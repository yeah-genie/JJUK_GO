# 네이버 카카오 도보 기능과 쭉고 차별화

기준일: 2026-10-28 (Asia/Seoul). 공식 도움말·기업 서비스 소개·공식 개발자 답변만 근거로 조사했다. 현재 소비자 앱을 설치해 동일 OD의 결과를 직접 비교한 조사는 아니다.

## 네이버와 카카오가 이미 제공하는 보행 기능은 무엇인가

### Takeaway

계단 회피 자체와 일반 도보 길안내는 차별점으로 주장하기 어렵다. 네이버는 현재 도움말에서 명시적으로 계단회피를 안내하고, 카카오는 오래전 다음 도보 서비스부터 계단제외를 소개했다. 카카오의 현재 앱 옵션 세부사항은 이번 공식 문서 조사만으로 확정하지 못했다.

### Cited Findings

- 네이버 도보 길찾기는 보행 가능 도로·횡단시설물·실내시설물을 조사한 기반이며, 검색 옵션은 추천·큰길우선·계단회피다. 계단회피 대상에는 계단과 에스컬레이터가 포함된다. 일부 실내 길찾기도 안내한다. — [네이버 현재 공식 도움말](https://help.naver.com/service/5637/contents/19164?osType=COMMONOS)
- 네이버 도보 길안내는 현재 위치 기반 실시간 경로 안내, 음성안내, 경로 이탈 시 재탐색을 제공한다고 공식 도움말에 설명돼 있다. — [네이버 도보 길안내](https://help.naver.com/service/5637/contents/25315?lang=ko&osType=MOBILE)
- 카카오의 현재 기업 서비스 소개는 자동차·대중교통·도보·자전거 길찾기를 제공한다고 명시한다. 이 페이지의 ‘바로 내비게이션’ 설명을 도보 턴바이턴 안내까지 의미한다고 해석하지는 않았다. — [카카오맵 서비스 소개](https://www.kakaocorp.com/page/service/service/KakaoMap)
- 다음 도보 길찾기 초기 출시 공식 보도자료는 계단·횡단보도 등의 시설 정보를 반영하고, 최단거리·계단제외를 선택할 수 있다고 설명한다. 문서 표시일은 2016-02-25지만 본문 출시 사건은 2012-01-16이다. 이는 역사적 기능 존재 근거이며, 2026년 앱의 옵션명·품질을 직접 증명하는 자료는 아니다. — [카카오 공식 초기 도보 출시 자료](https://www.kakaocorp.com/page/detail/6810)

### Inferences

- ‘네이버·카카오는 거리만 보고 계단을 모른다’는 설명은 피해야 한다. 특히 네이버 계단회피와의 차이를 별도로 설명해야 한다.
- 전국 검색 품질, 시설 정보, 실시간 위치 안내를 모두 따라 만드는 전략은 쭉고가 좁은 보행 불편 문제를 검증하는 데 필요한 비용을 키울 수 있다.

### Gaps

- 두 서비스가 현재 소비자 앱에서 도보 경로별 누적 상승고도·급경사 거리·예측 신호대기·출발 타이밍 최적화·시간 예산 내 다목적 비교를 어느 범위까지 제공하는지는 이번 공식 근거만으로 확정하지 못했다. **문서에서 못 찾았다는 것을 기능이 없다는 증거로 쓰지 않는다.**
- 카카오 현재 앱에서 계단제외 옵션이 남아 있는지, 적용 대상·성능이 무엇인지는 동일 OD의 실제 앱 확인이 필요하다.
- 신호 현시를 최적 경로 비용으로 내부 사용하지 않는다고 단정할 근거도 확보하지 못했다.

## 소비자 앱 기능과 공개 SDK API는 어떻게 다른가

### Takeaway

소비자 앱이 도보 길찾기를 제공하는 것과 개발자가 그 경로를 API로 받아 재가공할 수 있는 것은 별개다. 네이버 조사 대상 Directions API는 자동차용이다. 카카오 도보 API는 ‘아예 존재하지 않음’이 아니라 유료 제휴 경로가 있다는 최신 공식 답변이 있다.

### Cited Findings

- 네이버 Directions 5/15는 경유지를 포함한 경로 API이지만 공식 가이드는 자동차 경로에 한정한다고 설명한다. 이것으로 소비자 네이버 지도 앱이 도보 기능이 없다고 결론내릴 수 없다. — [Directions 5](https://guide.ncloud-docs.com/docs/application-maps-direction5-api-vpc), [Directions 15](https://guide.ncloud-docs.com/docs/application-maps-direction15-api-vpc)
- 카카오맵 API 공식 담당자는 2025-11-13 답변에서 오픈API로 도보 경로를 제공하지 않지만 URL 스킴으로 카카오맵 도보 길찾기에 연결할 수 있다고 안내했다. URL 스킴은 앱/웹을 여는 연결 방식으로 자체 라우팅 비용 함수를 바꾸는 API가 아니다. — [카카오 공식 답변](https://devtalk.kakao.com/t/api/147134)
- **2026-04-29** 카카오모빌리티 기술 제휴 담당자는 도보 길찾기 API가 제휴를 통해 제공되며, 단독 제휴는 불가능하고 유료 자동차 길찾기 API 제휴와 함께 진행해야 한다고 답했다. — [카카오모빌리티 공식 제휴 답변](https://devtalk.kakao.com/t/directions-api-navigation-api/149487)

### Inferences

- 기존 JJUK_GO 초기 기획서의 ‘카카오 도보 경로 API(경유 5개)’를 당장 무료로 쓸 수 있는 일반 API로 가정하면 안 된다. 후보가 될 수는 있으나 가격·계약·가공/저장/비교 허용범위를 먼저 확인해야 한다.
- 쭉고는 독립 보행 그래프에서 실험하고, 기본 경로 비교는 출처·버전·시간대를 기록한 합법적인 수동 벤치마크부터 시작하는 편이 현실적이다.

### Gaps

- 카카오 유료 제휴의 실제 가격, 학생 프로젝트 조건, 도보 응답 필드, 데이터 재가공·저장·타 지도 표시 조건은 확인하지 않았다. API 사용 승인을 받은 것도 아니다.
- 현재 신형 네이버 Maps의 모든 비공개·제휴 상품까지 없다고 판단하지 않는다. 확인 범위는 위 문서의 공개 Directions 5/15다.

## 쭉고가 어떤 차별화를 검증해야 하는가

### Takeaway

차별화 가설은 ‘계단 없는 길’보다 **추가시간을 제한하고 신호·경사·계단의 교환관계를 설명하는 개인별 도보 선택 도구**다. 기능 조합은 경쟁사도 구현할 수 있으므로 독점성보다, 특정 사용자·지역에서 효과를 증명하고 선호·검증 데이터를 쌓는 것이 중요하다.

### Cited Findings

- 계단회피가 이미 공식 기능인 네이버와 비교해야 하므로 단순 회피 옵션의 추가만으로 차별성을 주장하기 어렵다. — [네이버 도보 검색 옵션](https://help.naver.com/service/5637/contents/19164?osType=COMMONOS)
- 네이버는 이미 위치 기반 도보 길안내·재탐색을 제공한다. 쭉고가 일반 길안내 기본 기능의 존재를 독자적 강점으로 주장해서는 안 된다. — [네이버 도보 길안내](https://help.naver.com/service/5637/contents/25315?lang=ko&osType=MOBILE)

### Inferences

- **제안 1 — 시간 예산형 선택:** ‘최대한 편한 길’ 대신 ‘최단보다 +1분/+2분 안에서 덜 힘든 대안’을 제시한다. 숫자는 설명 예시다: ‘+80초로 신호 3곳·계단 1구간·상승 20m 감소’. 미확인 데이터가 있다면 같은 카드에 함께 표시한다.
- **제안 2 — 이유를 보이는 비교:** 계단회피 한 토글에 그치지 않고 빠른 길/쭉고 길의 시간, 신호, 계단 구간, 누적상승을 나란히 제시한다. 계단 없는 것이 확인되지 않았으면 ‘미확인’으로 쓴다. 임의 ‘편안함 87점’은 피한다.
- **제안 3 — 오늘의 이동 조건:** 짐이 많음·운동 후·계단이 싫음 등 맥락에서 선택이 달라지는지 검증한다. 다수 토글을 먼저 구현하기보다 선택실험의 조건으로 사용한다.
- **제안 4 — 신호의 시간축 결합:** 같은 길이라도 출발을 조금 늦춰 덜 멈추는지 경로 선택과 함께 보여준다. 이는 경쟁사에 없는 것으로 확정한 기능이 아니라 쭉고가 현재 보유한 신호 패턴 연구를 활용할 검증 가설이다.
- **축적할 자산:** 공공 지도 데이터 자체는 독점 자산이 아니다. 올바른 신호 방향 매칭, 구간별 검증 이력, 예측 불확실성·최신성, 실제 이용자의 시간-불편 선택 기록이 축적 가능하다. 이것도 모방 불가능한 방어벽이라는 주장은 하지 않는다.
- **좁은 첫 시장 후보:** 서울의 신호+경사/계단이 혼재한 반복 도보 구간. 통근·통학처럼 시간제약이 있으면서 작은 우회로 체감 차이가 날 수 있는 사용자를 검증 대상으로 제안한다. 사용자가 확정한 페르소나는 아니다.
- **기각 기준:** 동일 OD에서 네이버 추천/계단회피와 카카오 실제 경로가 이미 쭉고와 동등하거나 더 나으면 일반 편한길 주장을 축소한다. 선택실험과 실제 사용에서 의미 있는 선호·피로/대기 감소가 없으면 기능 확장을 보류한다.
- **최소 검증:** 같은 출도착지·요일·시각·보행조건으로 네이버 추천/계단회피, 카카오 현재 제공 옵션, 쭉고를 비교하고 추가시간·대기·계단·상승량·선택·재사용을 기록한다. 사용자별 선호와 목적을 분리한다. 비교 사이트에서 ‘결과를 잘 얻는다’만으로 체감 가치를 입증했다고 하지 않는다.

### Gaps

- ‘국내 유일’, ‘네이버/카카오는 못 한다’, ‘경사·계단 통합은 세계 최초’ 같은 독점성 주장을 뒷받침할 자료는 없다.
- 대안 경로의 발생 빈도, 실제 시간 손해, 사용자 지불/재사용 의사, 경쟁 앱 대비 체감 이득은 아직 실험 결과가 필요하다.
- 대중교통은 사용자 지침대로 Walking 검증 뒤로 미룬다. 이 조사를 지하철·버스 구현 승인으로 읽지 않는다.
