# Asphalt 디자인·동작 QA

2026-10-29. 기준은 사용자가 승인한 [네 이미지](ui/2026-10-29/asphalt/)와 [DESIGN_SYSTEM](../docs/DESIGN_SYSTEM.md), 실제 화면은 [구현 이미지](ui/asphalt-implementation/)다. 생성 시안 지리·12초 여유를 복사하지 않고 실제 OSM 지도/경로를 사용했다.

## 확인한 상태

- 첫 설문의 상대 걸음 선택, 다음/이전, 장비 복수·없음 선택, 설문 수정·건너뛰기. 속도 숫자를 묻지 않는다.
- 홈 미측정 상태, 실제 지도·장소 선택, GPS 시간 초과와 수동 선택 대체. 허구 GPS 점을 표시하지 않는다.
- 결과의 작은 행·노란 좌측 선택선·고정 걷기 버튼, 미측정/직접 걸음 적용과 ETA 재계산. 같은 경로이면 한 행만 보여 반복하지 않는다.
- 설정의 자동 기본·닫힌 직접 속도 메뉴, 수동을 켜면 자동 해제/반대 동작, 적용 후 출도착지 유지, 취소·설문 편집 복귀.
- 실제 설정 내부 스크롤: clientHeight 759px / scrollHeight 866px, 사용자 스크롤 후 scrollTop 약106px. 적용 버튼은 본문 밖에 남는다.
- 브라우저 iframe의 실제 viewport 360×640, 390×844, 768×1024에서 결과 배치·고정 CTA 확인. 별도 430×900 앱 영역에서 네 화면을 확인. 768에서는 단일 열 max-width 앱을 유지하며 넓은 지도용 데스크톱 사이드바는 이번 범위 밖이다.
- 걷기 진입, 실제 위치 연결 대기/실패, 종료. 위치를 얻지 못했을 때 거리·속도를 꾸며서 채우지 않는다.

## 발견·수정

| 중요도 | 발견 | 수정·재검증 |
|---|---|---|
| P1 | 화면 모듈 분리 중 이동 시연 플래그 정의가 빠져 걷기 초기화가 중단됨 | 공개 UI 시연을 false로 명시, 초기화 회귀 시험 추가. 실제 브라우저에서 지도·위치 대기·종료가 뜨는 것을 확인. |
| P2 | 360 화면의 계산 기준을 펼치면 지도 확대 버튼이 본문 위에 겹침 | 상세를 펼칠 때 지도 조작부를 숨기고 접을 때 복원. 수정본 360×640에서 펼침 시 지도 조작부가 사라지고 접을 때 복원되는 것을 AX와 이미지로 재확인. |
| P2 | 사용하지 않는 ‘이 구간도 필요해요’ 버튼이 남아 눌러도 반응 없음 | 실제 전송 기능이 없으므로 제거. |
| P2 | 장비 미응답이 ‘없음’처럼 보임 | equipmentAnswered를 분리하고 처음에는 선택 표시 없음·설정은 미응답 문구. 사용자가 직접 바꾼 계단 회피를 설문 재편집이 덮지 않음. |
| P2 | 어두운 지도의 큰길/동네·역 글자 대비가 낮음 | 밝은 지도 글자·어두운 halo, 조작 외곽선 #8793A3와 노란 thumb 토글. 실제 렌더 확인. |

색·밀도·스크롤·행동 버튼은 승인 방향과 일치한다. 최근 방문 이력이 없으면 샘플 방문을 만들지 않아 홈의 빈 여백이 생긴다. 개인 속도/횡단 자료가 부족하면 여유 초가 비어 보이는 것은 의도한 사실 표시다.

## 제한

브라우저 시험은 위치 제공 성공을 실제 야외 GPS로 검증한 것이 아니다. 개인 걸음 정확도·고령/보조기 사용자 현장 사용성·횡단 안전·지속 백그라운드 동작은 미완료다. 실제 신호 방향·길이·점멸 검증까지 마친 것처럼 이미지의 ~12초를 표시하지 않는다. 데스크톱 보조기기/스크린리더 전수 감사까지 수행하지 않았다.

최종 판정: 확인한 범위의 미해결 P0/P1/P2 없음. [시안/구현 비교](ui/asphalt-implementation/comparison.png), [360 상세 수정 후](ui/asphalt-implementation/360-details.png). 실기기·데이터 검증 제한은 별도 남는다.

운영 확인: `https://jjukgo.vercel.app/`에서 동일 설문/미측정 홈/예시 경로·실제 지도 확인, 오류 로그 0건. [운영 증거](ui/asphalt-implementation/production.png).

## 후속 사용자 수정 검증

인증 카드/로고는 삭제 상태를 유지하지 않고 최신 요청대로 복원했다. 홈 최근 두 곳과 CTA의 내용 높이를 맞춰 360×640에서도 잘리지 않으며, 현재 위치 SVG 중심은 버튼 중심과 약0px 차이다. 횡단 토글 제거·계산 기준 설정 이동, 공개 장소검색과 카드 PNG 저장을 브라우저에서 확인했다. [후속 보고서](WALK_CARD_LOCATION_SEARCH.md), [360 홈](ui/walk-card-location/360-home.png), [운영 인증 카드 예시](ui/walk-card-location/production-card.png). 확인한 화면 범위의 미해결 P0/P1/P2 없음. 실제 GPS 수신·야외 정확도는 별도 기능 검증 한계이며 완료로 세지 않는다.
