# 25. 신호 말고 다른 요소 찾기 (Sally, UX 디자이너)

2026-10-29 · 내 담당: 붐빔, 소음, 밤길 조명, 가로수 그늘, 날씨, 사고 많은 곳, 보호구역. 읽기와 웹 확인만 했다(코드·다른 파일 수정 없음, git 없음). 아래 추천은 **팀 제안이고 사용자가 승인한 것이 아니다.**

표시: **[확인]** 자료 페이지를 직접 열어 본 것 / **[검색]** 검색 결과 요약만 본 것 / **[추정]** 내 생각 / **[모름]** 못 확인.
자료 파일 자체를 내려받아 열어 본 것은 하나도 없다. 그래서 "몇 건인지, 좌표가 정말 맞는지"는 대부분 **[모름]**이다. 위치(좌표)가 "있다"고 쓴 것은 페이지에 그렇게 적혀 있다는 뜻이다.

## 0. 먼저 결론

### 추천 TOP 3
1. **"어르신 사고가 잦았던 곳" 표시 (도로교통공단 보행노인 교통사고 다발지역)**
   - 이유: 서울이 들어 있고 좌표·구역 모양이 있고 이용 제한이 없다 **[확인]**. 걸음 느린 분에게 와닿는 주제이고, 일반인도 "여기는 조심해서 건너야겠다"고 공감하기 쉽다 **[추정]**.
   - 조건: "위험하다/안전하다"로 쓰지 않는다. "지난 사고 기록이 많았던 곳"이라고만 쓴다(아래 UX 안 참고).
2. **가로수 위치를 "그늘이 있을 수 있는 길"로 옅게 보여주기 (서울시 가로수 위치 정보)**
   - 이유: 서울 전체 28만 건, 좌표(WGS84) 있음 **[확인]**. 자료는 이 중 가장 튼튼하다.
   - 조건: **그늘로와 겹친다.** 우리만의 무기가 아니라 "받쳐 주는 층"으로만 쓴다. 나무가 있다고 그늘이 진다는 보장은 없다(나무 크기·잎·시간 모름) **[추정]**. 이용 조건이 "상업 이용 금지·변경 금지"(공공누리 4유형)라서 사용자에게 확인이 필요하다(질문 1).
3. **"지금 붐비는 곳" 표시 (서울시 실시간 도시데이터, 주요 121장소)**
   - 이유: 인구가 몰린 정도를 4단계 같은 말로 주고 12시간 뒤 예측도 있다는 설명이 있다 **[검색]**. 지도에서 색 하나로 보여주기 쉽다 **[추정]**.
   - 한계: **서울 전체가 아니라 121곳뿐이다.** 좌표 칸은 못 찾았고 "장소 영역" 지도 파일이 따로 있다 **[확인]**. 그래서 길 위가 아니라 "큰 장소(관광지·역 주변 등) 단위"로만 가능하다. 인증키 필요.

### 하지 말 것 (자료가 없거나 위험한 것)
- **"밤길이 밝다/어둡다" 표시**: 서울 전체 보안등·가로등 위치 자료를 못 찾았다. 구별로 흩어져 있다(서대문구, 강동구 등) **[검색]**. 서울 전체를 못 덮는데 "밝은 길"이라 하면 틀린다.
- **"안전한 길·안심 길" 표시**(CCTV, 안심이 포함): 구별로만 있고 **[검색]**, 무엇보다 "안전" 단정 금지 조건에 걸린다.
- **"조용한 길" 표시**: 도로교통 소음 자료는 주요 지점 몇 곳뿐이고 좌표 여부도 못 확인했다 **[확인: 페이지에 좌표·지점 수 없음]**. 길 단위로 못 만든다.
- **노인보호구역 지도**: 서울 전체 한 파일을 못 찾았다 **[검색: 동대문구 일부만]**. 어린이보호구역 표준 자료는 "노인·장애인 보호구역은 제외"라고 적혀 있다 **[확인]**.
- **센서 기반 "여기가 지금 덥다"**: 센서 위치 파일을 못 열어 봤고, 2023년 보도에는 보안 이유로 위치를 비공개한다고 나왔다 **[검색]**. 지금은 페이지에 위치 파일이 있다고 쓰여 있어 **[확인]** 엇갈린다. 파일을 열어 보기 전에는 약속하지 않는다.

## 3. 화면(UX)으로 어떻게 보여주나 (내 담당이라 제안)

- **사고 다발 지역(1번):** 지도 위에 옅은 보라색(경고색 빨강 금지) 구역으로 칠한다. 이름은 "어르신 사고 기록이 많았던 곳". 눌렀을 때 "예전 사고 기록이 많았던 곳이에요. 이 길이 위험하다는 뜻은 아니에요. 건널 때 한 번 더 둘러봐요" 한 줄. "위험 구역", "안전" 단어는 쓰지 않는다.
- **가로수(3번):** 켜고 끄는 스위치 하나("나무 있는 길"). 기본은 꺼 둔다. 그늘로와 겹치므로 첫 화면의 주인공으로 쓰지 않는다.
- **붐빔(4번):** 큰 장소 위에 "지금 붐벼요 / 보통 / 여유" 3단계 글자 라벨. 색만 쓰지 않는다(색 못 구분하는 분 때문). "붐비는 곳은 걷는 속도를 맞추기 어려울 수 있어요" 같은 설명 한 줄.
- 요소를 늘릴수록 지도가 복잡해진다. **한 번에 층 2개까지만** 켜지게 하자는 게 내 의견이다 **[추정]**. 우리 핵심은 횡단보도 "내 걸음 N초"이므로 첫 화면은 그것만 둔다.

## 4. 확인하지 못한 것 (솔직히)

- 1번 자료의 서울 지점이 정말 몇 곳인지, 지금도 "실시간"으로 갱신되는지는 모른다. 페이지엔 "실시간"이라 적혔지만 수정일은 2026-09-07이다. 사고 "연도"가 몇 년치인지도 페이지에 없다.
- 2번이 서울을 포함하는지, 어린이보호구역(10번)이 서울 25개 구를 다 덮는지 모른다.
- 5·6번의 센서 위치 파일, 8번 서울 전체 보안등 자료, 13번 기상청 자료는 열어 보지 못했다.
- 검색 도구는 미국 기준이고 요약본을 주기 때문에, 서울 열린데이터광장 검색창에서 직접 "보안등", "노인보호구역"을 쳐 보면 내가 놓친 것이 나올 수 있다.
