## 잘 되어 있는 점 (유지)
- 스크롤바 없음(양 해상도, 전 화면), 가로 스크롤 없음, JS 오류 0건.
- 숫자 중심 위계: 내 걸음의 큰 노랑 `4.3km/h`, 걷기 화면의 `시간/걸은 거리/페이스` 3열, 도착 카드의 큰 숫자가 좋다.

- "뛰세요"류 문구 없음. "멈춰도 괜찮아요"는 방향이 맞다. 불확실한 값은 "추정", "미확인", "예시"로 표시한다.

## 발견 (우선순위 순, 6건)

### 1. [상] 핵심 버튼 하단이 화면 밖으로 잘림
- 화면: 홈, 걷기(그냥 걷기·경로 걷기) — 두 해상도 모두
- 재현: 390x844 또는 360x640으로 홈을 열고 시트 하단을 본다. 걷기 화면에서도 같다.
- 측정(버튼 top~bottom / 뷰포트 높이):
  - 홈 `예시 길 보기`: 801~850 / 844, 360폭은 601~646 / 640
  - 걷기 `걷기 끝내기`: 811~860 / 844, 360폭은 609~654 / 640
- 문제: 가장 중요한 버튼(시작·끝내기)이 6~16px 잘려 있고, 눈에 띄게 반쯤 걸쳐 보인다. 시트 안에서 스크롤은 되지만, 걷는 중에는 한 손으로 스크롤해서 찾아야 하는 버튼이 아니다. `그만 걷기` 쪽도 같은 줄에서 잘린다. (헤드리스에서는 safe-area가 0이라 실제 기기에서는 더 심할 수 있다. 실기기 확인은 아직 못 했음.)
- 수정안:
  - 걷기 시트 접힌 높이 계산에 `.sheet-footer`(또는 버튼 줄)를 포함해, 버튼 bottom이 `100dvh - env(safe-area-inset-bottom) - 12px` 이하가 되게 한다.
  - 임시 CSS: `.sheet-body{padding-bottom:calc(24px + env(safe-area-inset-bottom))}`, 홈/걷기 액션 줄은 `position:sticky;bottom:0`.
  - 걷기 화면은 `위치 다시 연결`·`움직임 시연` 줄을 접힌 상태에서 숨기면 높이가 확보된다(발견 6 참고).

### 2. [상] 결과 화면: 위계가 뒤집혀 있고 글이 많다
- 화면: 결과(서대문역→청계광장), 390/360
- 재현: 홈 `서대문역 → 청계광장` 칩 또는 `예시 길 보기`
- 문제:
  - 가장 큰 요소가 설명 카드(`이 조건에서는 같은 길이에요` + 2문장 40자)이고, 정작 핵심 숫자 `26분`은 오른쪽 카드 안에서 두 번째로 크다.
  - `계단 0구간 / 오르막 추정 약 51m↑ / 신호 5곳`은 좋지만 11px 라벨이다.
  - 11px 회색 한 줄 `08:40 예시 · 걸음 3.9km/h · 이력 추정 · 미확인 신호45초/곳 포함`은 정보가 4개 겹치고, `신호45초/곳`은 띄어쓰기 오류다.
  - `경로 정보·추정 기준 +2분까지`는 무슨 말인지 열기 전에는 알 수 없다.
- 수정안(문구):
  - 카드 제목: `이 조건에선 같은 길이에요` → `같은 길이에요`. 본문: `2분 더 걸어도 덜 힘든 길이 없어요.`(1문장)
  - 설명 카드는 아스팔트 면 대신 연한 면(`#fff`, 테두리 1px)으로 낮추고, 경로 카드의 `26분`을 `font-size:36px` 이상으로 키운다. 카드 타이틀 `✓ 추천 경로`는 `추천`으로 줄인다.
  - 메타 줄: `08:40 예시 · 3.9km/h · 신호 45초/곳 가정`. `이력 추정`은 `내 걸음` 한 곳에서만 말한다.
  - 접기 행: `경로 정보·추정 기준` → `계산 기준`.
  - `몇 분 더 걸어도 괜찮나요?` → `더 걸어도 되는 시간`. 칩은 `+0분/+2분/+5분/+10분`으로 통일(`같은 시간` 제거).

### 3. [상] 단위·시간 표기가 섞여 있고, 도착 카드 숫자가 오해를 부른다
- 화면: 내 걸음, 걷기, 결과, 도착 카드
- 문제:
  - 같은 "속도"를 내 걸음은 `4.3km/h`와 `페이스 13'53"/km` 두 가지로, 걷기 화면은 `페이스/km 15'25"`만 보여 준다. 사용자는 어느 쪽이 기준인지 모른다.
  - 시간 표기가 `26분`(결과), `2:01`(걷기), `25:43`(도착), `4:25`(기록)로 제각각이다. `2:00`이 2분인지 2시간인지 모호하다.
  - 도착 카드 `예상 25:43 · 실제 2:00 · 120m`는 1.3km 중 120m만 걷고 끝낸 기록을 "서대문역 → 청계광장 걷기"로 보여 준다. 끝까지 걷지 않았다는 신호가 없다. (시연 상황이라 그렇지만, 일찍 끝낸 실제 사용자에게도 똑같이 나온다.)
- 수정안:
  - 기준 단위는 `km/h` 하나로 통일하고, `페이스 ...″/km`는 내 걸음 상세에서만 보조(작게)로 둔다. 걷기 화면 3열 중 `페이스/km` → `속도` `3.9km/h`.
  - 시간은 1시간 미만이면 `26분 12초`/`2분 01초`, 1시간 이상이면 `1시간 05분`으로 단위를 붙인다. 콜론 표기(`2:01`)는 쓰지 않는다.
  - 도착 카드: 거리가 경로의 90% 미만이면 제목을 `걷기 · 서대문역에서 120m`로, 기대치 줄은 `예상 26분 · 실제 2분(120m 구간)`으로 바꾸고 "도착" 표현을 쓰지 않는다. 판단 근거가 약하면 `도착 여부 알 수 없음`으로 표시한다.

### 4. [중] '내 걸음' 진입이 약하다
- 화면: 홈
- 재현: 홈을 열고 내 걸음을 찾아본다.
- 문제: 시트 안의 흰 행(`내 걸음 4.3km/h 걸으면 내 속도를 재요 ›`)이라 정보 표시줄처럼 보이고, 라벨 `내 걸음`이 13px 회색이다. `그냥 걷기`는 그 안에서 한 번 더 들어가야 나오므로 "나이키 런의 걷기 버전" 역할이 홈에서 보이지 않는다. 기록이 쌓여도 홈 행은 바뀌지 않는다(`걸으면 내 속도를 재요` 고정으로 보임).
- 수정안:
  - `.pace-row`에 `border-left:4px solid #F6C343; min-height:52px`, 라벨 `font-size:15px;font-weight:700;color:var(--asphalt)`로 올린다.
  - 보조 문구는 상태 따라: 기록 없음 `기록 없음 · 보통 속도`, 기록 있음 `기록 1번 · 내 속도`. 기록이 있으면 숫자만 앞세운다.
  - 선택: 홈 액션 줄 위에 `그냥 걷기`를 작은 보조 버튼(44px)으로 직접 노출해 한 번 덜 들어가게 한다.

### 5. [중] 터치 타깃 44px 미달과 작은 글씨가 많다 (배리어 프리)
- 측정(390 기준, 360도 동일):
  - 뒤로 `‹` 32x32, 교환 `⇅` 32x32
  - 홈 마감 시각 `+`/`−` 44x32, 입력 48x39, `마감 없음` 77x35, 예시 칩 35px
  - 결과 `trip-pt`(출발/도착) 30~34px, `이 구간도 필요해요` 19px, `횡단보도 자세히 보기`·`다른 출발 시각 비교` 29px, 칩(`기준 시각`, `+1분`) 35px
  - 내 걸음 `기록 지우기` 29px
  - 걷기 `위치 다시 연결` 35px, `움직임 시연` 35px
  - 핸들 `grip-area` 높이 20px
- 글씨 12px 미만: 스케일 `50 m`(10.5), 결과 `계단·오르막 추정·신호` 라벨(11), 결과 메타(11), 내 걸음 칩 속 `3.2km/h`(11), 기록표 `거리/시간/페이스/멈춤` 및 날짜(11.5).
- 수정안(CSS):
  - `.icon-btn{width:44px;height:44px}`
  - `.chip,.link-btn,.trip-pt,[data-time-step]{min-height:44px}`
  - `.link-btn{padding:12px 0}`
  - `.grip-area{padding:14px 0 12px}`
  - 라벨·보조 숫자 최소 `12.5px`, 핵심 숫자 옆 단위는 `13px` 이상. `#result-note{font-size:12.5px}`
  - 멈춤 열에 `회`를 붙인다: `1회`(숫자만 있으면 의미를 모른다).

### 6. [중] 걷기 화면의 문구 중복·테스트용 컨트롤 노출
- 화면: 걷기(그냥 걷기, 경로 걷기)
- 문제:
  - 그냥 걷기에서 상단 카드의 `260m`와 하단의 `걸은 거리 260m`가 같은 값을 두 번 보여 준다.
  - 문구가 2문장이다: `목적지 없이 내 걸음을 기록해요` + `멈춰도 괜찮아요. 걷는 동안만 속도를 재요.`
  - 경로 걷기에서 `실시간 신호는 제공하지 않아요. 건널 때 실제 신호를 확인하세요.`가 노랑 굵은 2줄로 계속 떠 있어 `700m`보다 먼저 읽힌다(경고 반복, 안내 피로).
  - `움직임 시연` 칩이 일반 걷기 화면 하단에 상시 노출된다(테스트 컨트롤).
  - `다음 안내 700m`만 있고 무엇을 하라는 안내(방향·횡단보도)는 없다. 정보가 없으면 "모름"이라고 하는 게 낫다.
- 수정안(문구/구조):
  - 그냥 걷기 상단: 라벨 `그냥 걷기` + 큰 숫자 `260m`는 유지, 하단 `걸은 거리` 열을 `속도 3.9km/h`로 교체해 중복 제거. 설명은 `멈춘 시간은 속도에서 빼요.` 한 문장.
  - 신호 경고는 첫 진입 5초만 노랑으로 보여 주고 이후 `신호 정보 없음`(회색 12.5px 한 줄)로 축소.
  - 상단 카드 라벨 `다음 안내` → `남은 거리 1.3km`로, 알 수 없는 방향 안내는 표시하지 않는다.
  - `움직임 시연`은 URL `?demo=1`일 때만 보이게 하고, `위치 다시 연결`은 GPS 오류 상태일 때만 보인다.

## 한국어 문구 메모 (위 항목에 포함되지 않은 것)
- `걸으면 내 속도를 재요`(홈): `걸으면 속도를 재요`로 충분.
- `이 구간도 필요해요` 링크(결과): 무엇이 필요한지 모호하다. `이 구간 데이터 요청`.
- 기록 날짜 `10. 29. 오전 06:23` → `10월 29일 06:23`.

## 확인하지 못한 것 (모른다고 표시)
- 실제 iOS/Android 기기에서의 safe-area, 시스템 큰 글씨(글꼴 200%) 동작: 이번에는 헤드리스 Chromium만 사용해서 확인 못 함.
- 스크린 리더(VoiceOver/TalkBack) 읽기 순서와 포커스: 측정하지 않음. 아이콘 버튼의 `aria-label`은 코드 상 존재함.
- 일부 요소의 정확한 색 대비 수치는 계산하지 않았고, 눈으로 볼 때 문제는 없었다.
