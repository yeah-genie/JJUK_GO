# 서울시 신호 자료의 방향 설명 (2026-10-29 조사)

## 공식 페이지에 적힌 것
출처: [T Data 신호제어기 신호정보 및 잔여시간 API(10381)](https://t-data.seoul.go.kr/dataprovide/trafficdataviewopenapi.do?data_id=10381)

- `nt / et / st / wt` = 북쪽 / 동쪽 / 남쪽 / 서쪽, `ne / nw / se / sw` = 북동 / 북서 / 남동 / 남서
- `Pd` = 보행신호, `St` = 직진, `Lt` = 좌회전, `Ut` = 유턴, `Bs` = 버스, `Bc` = 자전거
- 잔여시간은 1/10초 단위
- 보행신호 상태값(`PdStatNm`)의 가능한 값 목록과 뜻은 **페이지에 없다**. 샘플에는 `stop-And-Remain`, `protected-Movement-Allowed`만 나온다.
- "북쪽 보행신호"가 **북쪽 길을 건너는 횡단보도**인지, **북쪽에서 오는 쪽의 신호**인지는 **적혀 있지 않다.**
- 담당: 서울특별시 미래첨단교통과 (페이지에 02-2133-4954, 02-2133-4960)

## 방향을 정확히 알려 줄 가능성이 있는 파일 (미확인)
같은 T Data에 있는 C-ITS 지도 파일(매일 갱신)이다. 신호등 번호와 차로·횡단보도를 이어 주는 자료일 가능성이 있으나, 컬럼 설명이 페이지에 없어 **받아서 열어 보기 전에는 모른다.**
- 신호연결 MAP 정보 `v2xSignalConnectionMapInformation.csv` (data_id 10146)
- Map 차로 정보 `v2xLaneMapInformation.csv` (data_id 10145)
- 노드 Map 정보 (data_id 10147)

이 작업 환경에서는 t-data.seoul.go.kr에 연결되지 않아 받지 못했다(SSL 연결 오류).
