# 25. 대중교통 연계 + 자료 목록 훑기 (Winston, 아키텍트)

2026-10-29 · 읽기와 웹 확인만 했다(코드·다른 파일 수정 없음, git 없음). 아래 판정은 팀 제안이고 사용자가 승인한 것이 아니다.

표기: **[확인]** 자료 페이지를 직접 열어 본 것 / **[검색]** 검색 결과 요약만 본 것 / **[추정]** 내가 이어 붙인 것 / **[모름]**.
자료 파일 자체(CSV 등)는 한 개도 내려받아 열어 보지 못했다. "좌표가 있다"는 말은 페이지 설명에 적힌 것까지만이고, 실제 칸 이름과 건수는 **[모름]**이다.

## 0. 먼저 알아 둘 것 (중요)

**서울시가 이미 "서울동행맵"이라는 교통약자 길안내 앱을 만들었다.** **[검색]** (2024.04.17 시범 시작, 아시아경제 기사)
- 휠체어 길찾기에서 **단차 2cm 초과, 경사 약 12도 이상, 보도 폭 1.2m 미만을 피한다**고 한다.
- 지하철 엘리베이터·에스컬레이터 위치를 반영하고, 저상버스는 정류장 30m 안에서 예약하면 기사에게 전달된다고 한다.
- 이용자가 불편한 곳을 신고하는 기능이 있다.
- 서울 전체에 적용되는지, 자료를 어디서 어떻게 모았는지는 기사에 없다 **[모름]**. 나는 앱을 직접 써 보지 못했다.
- 뜻: 우리가 "엘리베이터·단차·경사·보도 폭"으로 넓히면 **서울시 공식 앱과 정면으로 겹친다.** 우리의 차이는 "휠체어"가 아니라 "내 걸음 속도로 건너는 시간"이다 **[추정]**. 이 약속을 지키려면 새 요소는 "걷는 시간·기다림"과 이어지는 것이 좋다.

## 1. 맨 위: 추천 TOP 3

모두 **제안**이다. 아래 이유는 "자료가 확인된 정도"와 "컨셉에 이어지는 정도"로 골랐다.

### TOP 1. 버스정류소까지 내 걸음으로 걷는 시간

- 자료 **[확인]**: 서울시 버스정류소 위치정보 ([OA-15067](https://data.seoul.go.kr/dataList/OA-15067/S/1/datasetView.do)). 서울시 제공, 좌표 있음, 서울 전체(서울시 정류소 자료), 파일(CSV·XLSX)과 Open API, 데이터 갱신일 2026.09.02, 공공누리 1유형(출처만 밝히면 상업 이용·변경 가능).
- 주의 **[확인]**: 페이지에 좌표계가 "WGS84 (EPSG-5179)"로 적혀 있는데 이 두 이름은 서로 다른 좌표계다. 받아서 어느 쪽인지 확인해야 한다.
- 왜: 어르신이 가장 자주 하는 이동 중 하나가 "버스 타러 정류장까지 걷기"다 **[추정, 근거는 못 찾음]**. 이미 있는 보행 그래프와 "내 걸음으로 몇 분"을 그대로 쓰면 되고, 새로 필요한 것은 점 하나씩이다.
- 하지 말 것: 정류장에 "저상버스가 온다"고 쓰지 않는다. 저상버스는 노선 단위 자료이고(아래 B4), 오늘 이 정류장에 저상이 서는지는 모른다.

### TOP 2. 지하철 출입구까지 걷는 시간 (역 안 엘리베이터는 따로 조심)

- 자료 **[확인]**: 서울시 자치구별 도보 네트워크 공간정보 ([OA-21208](https://data.seoul.go.kr/dataList/OA-21208/S/1/datasetView.do)). 설명에 "횡단보도, 육교, 버스정류장, 지하철 출입구 등"이 나온다. 좌표계 WGS84, 갱신 매일, 공공누리 1유형. 단 **서울 전체인지 구별 일부인지 페이지로는 확정 못 함**, 내려받기 파일은 0.01MB로 매우 작아 설명서 같은 것일 수 있다 **[추정]**. 설명에 "2020년 기준"이라고 적혀 있다.
- 우리 보행 그래프(서울)와 같은 뿌리일 가능성이 높다 **[추정]**. 이미 가진 자료에 출입구가 들어 있는지부터 열어 봐야 한다. **새 자료를 구하지 않고도 될 수 있는 후보**라서 TOP 2로 둔다.
- 엘리베이터 위치는 따로 있다(B1). 하지만 좌표가 확인되지 않았고 오래됐다. 그래서 "출입구까지 걷는 시간"을 먼저 하고, 엘리베이터는 "있을 수 있다" 수준으로만 다룬다.

### TOP 3. 걷는 길 위의 "공식 정비 정보" 중 사용자에게 보여 줄 것은 없나 → 정보공개 요청 두 건

이건 자료가 아니라 **자료를 얻는 길**이다. 지금 공개 목록에는 없는데 서울시가 가진 것이 확인되는 것 두 가지가 있다.
1. **보도 전수조사 결과** **[검색]**: 서울시가 2019~2020년에 전체 보도 1,671km를 조사했고(평탄성·지장물, 횡단보도 턱낮춤·점자블록 등 포함, 장애인 27명 참여), 이 자료가 공개 데이터로 올라와 있는지는 못 찾음. 있다면 우리 컨셉("걸을 만한 길")과 가장 가깝다. 다만 2020년 자료라 낡았을 수 있다.
2. **보행신호 연장 123곳 위치** (23번 문서에서 이미 제안한 것): 위치 목록 비공개.
- 이유: 둘 다 "서울시가 걸음 느린 분을 위해 이미 파악한 것"이라 컨셉과 맞고, 우리가 새로 측정할 필요가 없다(현장 조사 불가라는 제약과도 맞음). 며칠~몇 주 걸린다.

### 하지 말 것

- **저상버스 도착을 "지금 저상이 온다"처럼 보여 주기.** 서울 버스 도착정보 API에서 저상 여부를 나타내는 칸이 있는지 확인하지 못했다 **[모름]**. 노선 자료에는 "금일 저상버스 첫차·막차 시간"만 있다 **[확인]**.
- **엘리베이터를 "쓸 수 있다"로 표시하기.** 실시간 가동 여부 자료를 못 찾았다. 위치 자료도 2022년 이후 수정 기록이 없다(B1).
- **공중화장실 지도**(23번에서 이미 결론: 좌표 끊김).
- **"장애인편의시설" 자료를 길 위의 점으로 찍기.** 좌표 칸이 없다(B5). 주소를 좌표로 바꾸면 틀릴 수 있고, 대부분 건물 안 시설이다.
- **약자동행지수**: 서울시 정책 평가 점수(6개 영역 50개 지표)라 구 단위 통계이고 길 위의 위치가 없다 **[검색]**. 쓸 수 없다.
- **노후 포장도로 정비 현황**: 차도 포장 공사 자료이고(재난안전실 도로관리과) 좌표 여부 불명, 데이터 소식 목록에 "서비스 종료 안내" 문구도 보임 **[확인]**. 보도가 아니라 차도라 컨셉과 거리가 멀다.

## 4. 목록 훑기에서 새로 건진 것 (그리고 접은 것)

- **새로 건짐**: ① 버스정류소 위치(B3), ② 노선별 "저상버스 첫차·막차 시간" 칸(B4), ③ 도보 네트워크의 "육교·지하철 출입구" 설명(B7), ④ 보도 전수조사라는 존재(B8).
- **이미 알던 것과 같음**: 횡단보도 위치([OA-22906](https://data.seoul.go.kr/dataList/OA-22906/S/1/datasetView.do), 서울 전체, 경도·위도 있음, 갱신 2026.04.22, 제한 없음) **[확인]**. 이미 쓰는 횡단보도 자료일 가능성이 높다 **[추정]**. 이 자료 설명에는 "횡단보도 종류" 칸이 있어 신호 유무 같은 구분이 있을 수 있으나 **[모름]**.
- **못 찾음(검색에 안 나옴 = 없다는 뜻이 아님)**: 보도 폭, 턱낮춤 위치, 점자블록 위치, 안전섬, 음향신호기, 저상버스 개별 차량 위치, 승강기 고장 정보. "보행"·"보도"·"교통약자" 검색은 열린데이터광장 전체를 훑는 방법이 아니라 검색 엔진으로 한 것이라, **열린데이터광장 사이트 안에서 직접 검색한 결과가 아니다.** 사이트 검색은 내가 접속은 되지만 목록 화면을 요약기 없이 보지 못했다. 이 부분은 사람이 한 번 직접 검색해 보면 좋다.

## 5. 사실 확인에서 조심할 점

- 열린데이터광장 페이지마다 "서비스 종료 안내" 문구가 붙어 있다. 템플릿 문구인지 해당 자료가 끝난다는 뜻인지 **[모름]**. 내려받을 때 실제로 되는지 봐야 한다.
- 자료 두세 개는 "파일이 없습니다"로 나온다(OA-23030, OA-23130, OA-12036). 이 경우 Open API 인증키가 필요할 수 있다. 서울시 일부 API는 "신규 인증키 발급 불가" 안내가 있다고 한다 **[검색, 확인 못 함]**.
- 저상버스 비율은 2020년 기준 서울 57.8%라는 숫자를 한 분석 글에서 봤지만 최신 아님 **[검색]**. 앱 문구에 쓰지 않는다.

## 6. 쭉고 약속과의 관계 (제안)

- B3·B7(정류소·출입구)은 "내 걸음으로 몇 분"이라는 약속을 **넓히지 않고** 목적지만 늘린다. 컨셉이 흔들리지 않는다.
- B1·B4·B13(엘리베이터·저상버스·승강장)은 "휠체어·배리어프리 길안내" 쪽이라 **서울동행맵과 겹친다.** 사용자가 나중에 확장하고 싶다고 한 방향이므로 "나중"으로 두고, 지금은 자료가 있는지만 알아 둔다.
- 어떤 요소든 문구에 "안전", "보장", "무장애", "이용 가능"을 쓰지 않는다.

## 7. 가장 싼 확인 (각 30분 안팎)

1. OA-15067 CSV를 받아 건수, 좌표 칸, 좌표계, 서울 모양으로 찍히는지 본다.
2. 이미 있는 보행 그래프 파일에 "지하철 출입구"·"육교"가 들어 있는지 칸 이름만 본다(OA-21208과 같은 뿌리인지도 같이).
3. 열린데이터광장에서 "엘리베이터"를 직접 검색해서 B1과 다른 최신 자료가 있는지 본다.
4. 서울동행맵 앱을 직접 한 번 써 보고 우리 컨셉과 겹치는 화면을 적는다(앱 접근 필요).

## 8. 못 한 것

- 자료 파일 열기(건수·칸 이름·좌표 품질). 위의 "좌표 있음"은 페이지 설명 수준이다.
- 열린데이터광장 사이트 안 목록 검색(검색 엔진으로 대신함). 공공데이터포털(data.go.kr) 안 목록 검색도 마찬가지.
- 서울동행맵 직접 사용, 저상버스 도착정보 API 명세 확인.
