# 스레드 데모 캡처 (2026-11-01)

모두 `jjukgo` 새 화면(reference-ui)을 실제 엔진으로 돌려 찍었다. 숫자는 그 시각에 앱이 보여 주는 값 그대로다.

**촬영 조건(꼭 함께 알릴 것)**
- **시각:** 화요일 2026-10-27 14:10 KST로 고정했다. 신호 패턴이 가장 많은 평일 낮이고, 밤·아침에는 신호가 대부분 '모름'이다.
- **지도:** 작업 환경에서 네이버 지도가 뜨지 않아 기본 지도(OpenStreetMap 기반)로 찍었다. 실제 사이트는 네이버 지도다.
- **위치:** 가짜 GPS로 경로를 따라 이동시켰다. 실제 현장에서 걸은 기록이 아니다. "직접 걸어 보니"라고 쓰지 않는다.
- **신호:** 신호 숫자는 과거 신호 기록으로 낸 **예상**이다. 실시간이 아니다.

## 스레드 글 초안 (데모 회의 문구 규칙에 맞춤, 제안)
1. 걷다가 횡단보도에서 자꾸 멈추는 게 싫어서 만들고 있는 서울 도보 길찾기 '쭉고'예요. 신호가 바뀌기까지 남은 초를 지도에 띄워요. 과거 신호 기록으로 계산한 예상이에요(실시간 아님). [영상]
2. 길을 고를 때 걷는 시간만이 아니라 계단·급경사·신호 대기까지 같이 세요. 성수역→서울숲은 도착 시간이 거의 같은데 신호 3곳, 급경사 80m가 덜한 길이 있었어요(예상). [3번 사진]
3. 더 나은 길이 없으면 억지로 추천하지 않아요. [대안 없음 화면은 추가 촬영 필요]
4. 평일 낮에 가장 잘 보여요. 아직 만드는 중이라 피드백 환영해요. jjukgo.vercel.app

쓰지 않을 말: 실시간, 정확한, 안전한 길, 무장애, 보장, 뛰세요, 네이버·카카오보다 낫다, 직접 걸어 보니, 버스.

다시 찍기: `node scripts/preview.cjs &` 뒤 작업 환경의 촬영 스크립트(shots.cjs, video.cjs)를 쓴다. 고정 시각과 가짜 GPS를 쓴다.
