# 로고·인증 카드·위치·레이아웃·장소 검색 수정

2026-10-29 · 사용자 후속 요청. 이전 공유 카드/시작 로고 제거 결정을 변경한다.

## 변경

- 첫 로고: 횡단보도 위로 노란 차선이 등장하는 로고를 복원. 지도 초기 준비와 병행해 시작부터 최소 약 3.2초 표시하고, 준비가 끝나면 건너뛸 수 있다.
- 인증: 걷기 끝내기에서 노란 궤적·거리·시간·날짜·쭉고가 있는 카드와 PNG 이미지 저장. raw GPS는 세션 메모리에만 둔다. 앱을 다시 열면 복구하는 활동 목록이 아니다. 부정확/끊긴 위치 사이를 임의로 잇지 않는다. 실제 궤적이 없으면 예시/계획 경로라고 표시하고 실제 운동 기록으로 꾸미지 않는다.
- 잘림: 고정 비율로 본문 높이를 잘라 두지 않고 실제 내용과 고정 CTA 높이로 시트 크기를 정한다. 정상 폰에서 최근 두 곳+예시 보기+버튼이 다 보인다. 큰 글씨/극단적으로 짧은 화면에는 접근성상 내부 스크롤을 허용한다.
- 횡단 정보는 항상 표시, 토글 제거. 계산 기준과 허용 추가시간 설명은 설정. 결과에는 짧은 횡단 정보 상세 진입만 유지.
- 현재 위치 아이콘: 버튼을 grid/place-items:center로 정렬하고 SVG baseline·padding 영향을 없앴다. DOM 측정 중심 차이 x/y 약 0.000001px.
- GPS: 초기 요청은 빠른 일반 위치/최근 30초 캐시로 하고, 실패/오차가 크면 정밀 위치를 한 번 더 요청한다. 권한 거부는 재시도 루프를 만들지 않는다. 정밀 실패 시 오차 100~1000m의 일반 위치는 확인용으로만 제시한다. 100m 초과 위치를 확정 경로로 자동 출발시키지 않는다. 걷기 watch의 시간 한도를 30초로 조정하고 실패 이유/기기·브라우저 위치 설정/외부 브라우저 이용 안내를 제공한다.

## 장소 검색

기본 OSM 약1.7만 장소 목록은 입력 중 빠르게 검색한다. ‘공개 지도에서 더 찾아보기’에서만 `/api/places`가 Photon 공개 서버를 요청한다. 고정 서울 bbox·12개 제한·8초 타임아웃·응답 검증·10분/100항목 인스턴스 캐시·500ms 간격 제한·CDN 캐시를 사용한다. 이는 분산 시스템 전체의 요청 제한이 아니므로 사용량이 커지면 자체/계약 서버로 전환해야 한다. 검색에 GPS 좌표를 전달하지 않는다. 광화문 실제 호출 HTTP200, 기존 목록에 없던 출입구·건물·가게가 추가되는 것을 브라우저에서 확인했다. 모든 가게/주소를 찾는다고 보장하지 않는다. 경로 계산은 기존 서울 보행망이므로 출입구 연결/실제 통행 검증은 그대로 필요하다.

카카오 키가 없다는 사용자 답에 따라 유료 계정·키 발급·권한 확대를 하지 않았다. 이후 국내 장소 품질을 높이려면 카카오 Local REST API 등의 별도 키와 이용 조건을 확인해 교체한다. 현재 지도의 벡터 타일을 카카오 지도 SDK로 바꾼 것은 아니다.

근거: [W3C Geolocation](https://www.w3.org/TR/geolocation/)의 accuracy/timeout/maximumAge와 오류 구분, [MDN](https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API/Using_the_Geolocation_API), [Photon 공식 공개 서버 정책](https://github.com/komoot/photon/blob/master/README.md), [카카오 Local 공식 문서](https://developers.kakao.com/docs/en/local/dev-guide). 브라우저 권한/운영체제가 위치를 제공하지 않는 문제를 웹 코드가 강제로 해제했다고 주장하지 않는다.

### 남은 GPS 문제

운영 내장 브라우저의 실제 초기 위치 요청도 확인했다. 빠른 요청→정밀 재시도 후 위치값을 받지 못해 실패 안내가 표시됐다. 이 실패는 해결 완료로 세지 않는다. 실패 시 홈 본문 content/clientHeight 모두257px로 안내와 CTA도 잘리지 않았다. 실제 Chrome/Safari·휴대전화 수신과 야외 학습 검증이 남아 있다. 수신하지 못한 좌표나 이동 기록을 임의로 채우지 않았다.
