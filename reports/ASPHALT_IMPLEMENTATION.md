# 아스팔트 화면·내 걸음 맞춤 구현

2026-10-29. 사용자 승인 시안에 맞춰 기존 프로토타입의 지도·검색·보행 경로 엔진을 이어서 구현했다. 완전히 새 앱을 만들거나 시안 이미지를 실제 지도로 사용하지 않았다.

## 변경

- 짙은 아스팔트 바탕·차선 노랑, 실제 OSM 벡터 지도, 간결한 상단 출도착지, 작은 경로 행과 고정 걷기 버튼. 시간 막대·출발 카운트다운·운동 기록 화면 제거.
- 상대적 걸음 4답 + 이동 보조기 6답의 선택 설문. 언제든 건너뛰기. ‘없음’은 다른 장비 선택 해제, 나머지는 복수 선택. 장비를 속도에 대응시키지 않는다. 유모차/보행기는 확인된 계단 피하기를 초기 제안한다.
- 자동 맞춤 기본. 숫자 없는 ‘아직 측정 전’, ‘알아가는 중’, ‘내 걸음 반영’, 수동, 측정 꺼짐 상태. 수동 속도 슬라이더는 설정의 닫힌 하위 메뉴에만 있다.
- 자동 측정은 사용자가 시작한 GPS 길 안내 중 관측만 이용한다. 완료·이탈 때 유효 요약을 반영하며 위치 경로/활동 목록은 새로 저장하지 않는다. 화면 잠금·백그라운드 연속 작동은 보장하지 않는다.
- 계단 회피를 두 경로의 탐색에서 모두 강제한다. 알려지지 않은 턱·계단은 없다고 추정하지 않는다. 무장애 경로 보장이 아니다.
- 횡단 여유는 현재 **전부 미확인**이다. 개인 속도를 알아도 방향·횡단 길이·점멸 검증이 부족하므로 `~12초`를 실데이터처럼 출력하지 않는다. 승인 이미지의 이 숫자는 미래 상태의 시안이다.

## 모듈과 값

`docs/prototype/src/walking-profile.js`가 저장 스키마와 속도 범위의 단일 기준이다. 기본 임시 속도는 1.0m/s이며 국민 평균·사용자 측정값이라는 뜻이 아니다. 설문 상대 속도만으로 수치를 만들지 않는다. 수동 범위 0.2–2.2m/s(0.72–7.92km/h). 범위 밖 보행자를 배제하는 분류가 아니라 이번 추정기의 처리 범위이며, 경계값·GPS 저속 성능은 현장 검증 대상이다.

위치 정확도 20m 이하, 관측 구간 최소 20초, 중단 30초 초과 제외. 거리 변화가 양 끝 정확도의 합과 4m보다 크지 않으면 최대 90초 기다린다. 정지·차량 수준 점프를 제외한다. 유효 이동 120초 및 4개 구간 이상, 속도 중앙값/MAD 일관성을 만족해야 첫 속도를 반영한다. 이 임계치는 연구로 검증된 보편값이 아니라 데모의 보수적인 구현 규칙이다. 0.25m/s 시험 포함. GPS로 구별 안 되는 매우 느린 걸음은 임의의 빠른 값으로 바꾸지 않는다.

학습은 현재 세션의 구간이 기준을 충족할 때만 수치로 확정된다. 여러 짧은 세션이 각각 기준 미달이면 아직 측정 중으로 남는다. 개인 속도는 이동 중 수시로 바뀌므로 횡단 안전 판정에 사용하지 않는다. 요약 저장 OFF는 접속 중 메모리를 유지하되 지속 저장값에서 과거 학습 요약도 제거한다. 다시 접속하면 측정 전이다. 초기화 버튼은 두 번 누른 뒤 즉시 적용하며 취소 대상 설정 초안과 구분한다.

`src/screens.js`는 화면·설문·설정, `src/asphalt.css`는 스타일, `src/template.html`은 DOM, `src/app.js`는 지도·경로/GPS다. `python scripts/build_prototype.py`로 합쳐 `index.html`을 만든다. HTML은 template.html 한 곳에서 수정한다. 옛 마감/운동기록 화면만 시험하던 check_prototype_ui.cjs/check_walk_browser.cjs는 삭제하고 현재 셸 구조 시험과 브라우저 검증으로 대체했다.

## 검증 상태

- Node `scripts/check_profile.cjs`: 콜드 스타트, 장비 배타·복수, 저속 0.25m/s, 차량 점프·정지·중단, 수동·측정 중지, 좌표 비저장, 초기화·손상 설정 통과.
- Node `scripts/check_walk_logic.cjs`: 신호 방향/유효 시간, 경사 방향, 추가 시간 예산, 경로 투영, GPS 오류/늦은 응답, 재시도·출입구 연결·목적지 보존 통과.
- 브라우저: 설문 두 단계·장비 복수/없음, 미측정 홈, 실제 지도/예시 경로, 설정 하위 속도 메뉴 확인. 나머지 최종 브라우저 결과와 배포 식별자는 HANDOFF에 추가한다.
- 실제 휴대전화 야외 걷기, 느린 걸음·유모차/보행기 사용자의 재현성, 현장 신호와 통행 가능성은 아직 검증하지 않았다.

- Python 전체 시험: 59개 통과(2.48초). 기본 임시 디렉터리 권한 오류가 있어 작업 폴더 안 전용 임시 디렉터리를 지정한 뒤 전부 통과했다.

- 최종 브라우저: 360/390/768 viewport에서 경로·스크롤/CTA 확인, 360 상세 조작부 겹침 수정 후 재확인, 걷기 초기화 오류 수정 후 지도·위치 대기 확인. 자세한 증거는 [design-qa](design-qa.md).
