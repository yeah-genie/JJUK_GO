### 추천 품질 기준 (app.js `altRejectReason`)
쭉고 길은 아래를 **모두** 통과할 때만 보여 준다. 하나라도 걸리면 "대안 없음"(빠른 길만).
- 추가 시간 10초 초과, 3분(설정한 허용 시간) 이하
- **너무 돌아가지 않음:** 추가 시간 ≤ max(60초, 빠른 길 걷는 시간의 25%)
- **사실상 같은 길이 아님:** 겹침 90% 미만, 겹치지 않는 구간 60m 이상
- **다른 요소가 크게 나빠지지 않음:** 신호 횡단·계단·큰길 횡단 증가 0, 전체 횡단 +1까지, 오르막 +5m, 급경사 +50m, 예상 대기 +20초까지
- **개선량이 충분함:** 신호 횡단 1곳↓ / 계단 1구간↓ / 오르막 10m↓ / 급경사 100m↓ / 예상 대기 30초↓ 중 하나 이상
- **개선량에 비해 추가 시간이 크지 않음:** 신호 1곳당 60초, 계단 1구간당 180초, 급경사 1m당 1.2초, 오르막 1m당 9초, 예상 대기는 줄어든 초만큼까지
