# 쭉고 화면 기획

**쭉고** — 걷다가 자꾸 멈추는 게 싫은 사람을 위한 도보 길찾기. 거리뿐 아니라 횡단보도와 예상 신호대기까지 계산해, 더 매끄럽게 걸을 수 있는 길을 찾는다.

- 프로토타입: [`prototype/index.html`](prototype/index.html) (브라우저에서 열면 `#home` `#result` `#detail` `#walk` `#done`으로 화면 이동)
- 스크린샷: [`assets/prototype/`](assets/prototype/)
- 모든 대기시간·신호 값은 **예시**다. 화면 상단 배지로 항상 표시한다.

## 그늘로와 다르게 보이게 하는 세 가지
1. **색은 도로에서**: 브랜드는 차선 노랑 `#F6C343`, 글자는 아스팔트 `#2A3140`. 초록·빨강은 신호 마커에만 쓴다. (한국 보행신호엔 노란불이 없어 헷갈리지 않는다.)
2. **멈춤 띠**: 경로를 이동 시간 막대로 그리고 기다리는 구간만 빨간 칸으로 끊는다. 쭉고 띠는 거의 끊기지 않는다.
3. **지도 위 경로 표현**: 쭉고는 끊김 없는 노란 실선, 최단은 회색 점선. 횡단보도마다 "도착할 때 예상 상태" 마커(✓ 통과 / Ⅱ 대기 + 초).

## 화면
| 화면 | 할 일 |
|---|---|
| ① 홈 | 지도 + "어디로 걸어갈까요?" + 회사/집/최근. 신호 패턴을 아는 구간인지 한 줄 안내 |
| ② 경로 결과 (핵심) | 쭉고 vs 최단: 소요 시간, 멈춤 횟수, 기다림, 멈춤 띠. 출발 시각 칩(지금/+1분/+3분)을 바꾸면 다시 계산. "걷는 거리는 비슷하고, 2분 5초 덜 기다려요" 같은 한 줄 |
| ③ 횡단보도 상세 | 경로의 횡단보도별 도착 예정 시각, 예상 상태, 근거 |
| ④ 걷는 중 | 다음 횡단보도까지 거리와 도착 시 예상 상태. 빨강 예상이면 "천천히 가도 괜찮아요" (절대 뛰라고 하지 않음) |
| ⑤ 도착 공유 카드 | 러닝 앱 기록 카드처럼 경로 실루엣(노란 선, 멈춘 곳만 빨간 점) + 멈춘 횟수 / 신호 기다림 / 걸은 시간 + "최단으로 갔다면 4번 멈췄을 거예요" |

## 원칙
- 숫자는 모두 예상값. 신호 정보가 없는 횡단보도는 회색 "–"로 구분한다.
- 안전 문구: "예상값이에요. 건널 때는 신호를 꼭 확인하세요."
- 말투는 짧고 쉬운 존댓말. 버튼은 하는 일을 그대로 쓴다("쭉고로 걷기 시작").
- 글꼴: 숫자·로고 Black Han Sans, 본문 IBM Plex Sans KR.

## 프로토타입의 계산 방식
- 걷는 속도 1.2m/s, 지도 1px = 2m.
- 횡단보도마다 예시 신호 계획(주기·초록 시간·시작 오프셋)을 두고, 도착 시각의 위상으로 대기를 계산한다. 실제 서비스에서는 이 계획 자리에 수집한 신호 패턴이 들어간다.
- 2초 넘게 기다리면 "멈춤" 1번으로 센다.

## 확장 (나중)
내 걸음 속도 맞춤 → 느린 걸음 모드(어르신·유아차·휠체어) → 출발 타이밍 추천 → 안 멈추는 러닝·산책 코스 → 대중교통 연결 → 서울 신호 리포트.
