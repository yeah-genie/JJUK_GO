## 확인 및 통합

fetch 결과 기본 브랜치는 `67e7788`에서 `cdd1f6f`로 전진했다. 기존 prototype 커밋 `56c33d0`까지 이미 포함돼 있었다. 이후 원격에는 결과/걷기/요약 화면, 도착 기준 신호 안내, 신호 대기 포함 시간, GPS 따라가기, 공유, 출발 시각, Wake Lock, 음성이 추가됐다. 운영은 `cdd1f6f`를 소스로 READY였고 `/`는 `/reference-ui/`로 연결돼 있었다.

이 변경을 보존한 채 로컬 수정 `e0df577`을 병합했다. UI를 과거 버전으로 되돌리거나 원격 파일을 통째로 덮지 않았다. 이번 사용자 배포 요청은 이전의 prototype만 검토/운영 미배포 제한을 이 릴리스에 대해 갱신한다.

## 반영 범위

- 기존 신뢰 기준을 통과한 패턴은 현재/도착 시각 기준 예상 안내와 초읽기를 유지한다. 물리적 실시간 관측이라고 표시하지 않는다.
- 지속시간만 있는 단일 방향 기록은 클릭 상세에서 선택적으로 기록 패턴 재생. 처음 3→2→1은 실제 현재 위상이 아니라 임의 시작점의 시연이다. '현재 신호 아님'을 표시하며 지도 아이콘을 가짜 현재 초록으로 바꾸지 않는다.
- 모델 갱신 때 과거 기록/도착 상태의 선택 필드를 초기화하여 이전 신호 정보가 잔류하지 않도록 했다.
- 초읽기 갱신 때 네이버 마커 버튼을 교체하지 않아 키보드 포커스/클릭 대상이 유지된다.
- 자세히 펼치면 위 화살표와 '접기', 닫으면 아래 화살표와 '자세히'.
- 홈 출발·도착 X는 해당 장소만 지운다. 검색 응답이 늦게 도착해 최신 결과의 선택 인덱스를 바꾸는 경쟁 상태를 막았다.
- 팝업 위치는 지도 높이를 고려한다. 원격의 도착 기준, 경로 대안 선, 걷기 진행 기능을 보존했다.

## 검증과 제한

- Node reference UI, walk logic, profile, app shell, places, events, live 검사 통과. Redis 실제 서버/캐시는 기존 검사에서 미설치로 SKIP.
- Python 83개 통과. 최초 기본 임시 폴더 생성 오류로 44 setup error가 났고, 작업 폴더 안 별도 basetemp로 재실행해 전부 통과했다.
- reference/기존 앱 빌드 재생성, JS syntax 검사, diff 공백 검사 수행.
- 이번 수정의 새 브라우저 시각 검증은 자동 승인 검토의 토큰 갱신 실패로 실행되지 않았다. refresh token revoked, 재로그인 필요. 다른 브라우저 자동화로 우회하지 않았다. 과거 스크린샷을 이번 변경 검증으로 재사용하지 않았다.
- 야외 GPS/실제 신호와의 일치는 미검증. 기록 재생은 신호 정확도 검증을 대신하지 않는다.
