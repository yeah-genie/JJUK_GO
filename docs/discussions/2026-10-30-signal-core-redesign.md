# 신호등을 핵심으로: freeze 해제와 UI 개편 결정 (2026-10-30)

## 사용자 말(요약)
- "이 서비스는 신호등이 핵심. 카카오맵이 지하철 들어오는 걸 실시간으로 보여주듯, 지도에서 신호등이 바뀌는 걸 살짝 보여주고, 길찾기에서도 신호 예측을 제공해야(완성도는 점점 올라감) wow 포인트."
- GPT가 만든 목업(색·톤은 다름)의 신호등 아이콘과 오른쪽 1~5번 기능은 살린다. 색을 빼면 목업 디자인이 깔끔하니 UI를 바꿀 거면 바꾼다.
  1. 다음 횡단보도 집중 표시 2. 예상 신호대기 시간 비교 3. 도착 시점 기준 안내 4. 주변 신호 약하게 표시 5. 실시간 데이터 신뢰도 표시

## 사용자 결정(질문에 대한 답)
| 질문 | 결정 |
|---|---|
| '횡단 가능 · 17초 남음', '현재 속도면 건널 수 있어요' 문구(기존 '건널 수 있는지 판단하지 않는다' 규칙과 충돌) | **목업대로 '건널 수 있어요'를 쓴다** (규칙 변경) |
| 새 API 승인 전 지도 신호 아이콘 | **과거 기록 패턴으로 '예상' 표시**, 승인되면 같은 아이콘을 실시간으로 |
| UI 개편 시기 | **스레드 데모 전에** (RC freeze 해제) |

## 구현 원칙(결정을 지키면서 틀릴 위험을 줄이는 방법)
- '건널 수 있어요'는 근거가 모두 있을 때만: 신뢰 조건을 통과한 신호 패턴(또는 검증된 실시간) + 횡단보도 길이 + 도착 시각의 남은 '고정 초록' ≥ 내 속도로 건너는 시간 + 여유. 근거가 패턴이면 '예상'을 붙인다. 하나라도 없으면 상태만('도착 때 초록 예상') 또는 '신호 정보 없음'.
- 점멸(permissive)은 여전히 초록으로 세지 않는다(의미 미확정).
- 지도 아이콘: 경로 위 신호는 크게, 주변 신호는 작고 흐리게. 모양+색(보행 사람/정지 손/모름 ?). 패턴 예상은 점선 테두리, 실시간은 실선(승인 뒤).
- 신뢰도 표시: 지도 오른쪽 위에 '패턴 예상 · 10/14~10/27 기록' 또는 '실시간 · N초 전'.
- 버스·자동차 탭 등 목업의 다른 이동수단은 넣지 않는다(새 기능 아님 → 범위 밖).
- 색은 기존 쭉고 토큰(어두운 아스팔트 + 노란 차선) 유지, 신호 의미색(초록/빨강)만 아이콘에.
