## 실제 작업

- 기존 작업 checkout에서 원격 최신 `ccr-94bac9df-i81579`의 `b9c6b03`까지 받아 새 브랜치 `codex/reference-ui-prototype`에서 진행했다. Claude의 최신 신호/경로·디자인 제안 작업을 되돌리지 않았다.
- `docs/prototype/reference-ui/`에 새로운 HTML/CSS/화면 어댑터를 만들었다. 기존 보이는 카드 HTML/CSS를 재활용하지 않았다. 기준 화면을 임의로 추가하지 않았다.
- `scripts/build_reference_ui.py`는 기존 엔진을 읽어 전용 엔트리만 생성한다. 운영 `docs/prototype/index.html`과 `src/`는 수정하지 않았다. 원본 빌더도 수정하지 않았다.
- 현재 운영 사이트에서 추출한 브랜드 색을 사용한다. 새 화면은 밝은 바탕, 진한 글자, 노란 주 CTA, 파란 지도 경로, 초록/빨강/회색 횡단이다.
- 시각 재현의 `sample=1`과 실제 데이터 모드를 분리했다. 샘플 숫자·경로를 실제 신호·GPS 기록으로 저장하거나 계산하지 않는다. 프로토타입 저장소 키도 운영 키와 분리했다.
- 다음 횡단 말풍선은 MapLibre 마커의 자식 요소다. 지도 이동·확대 시 해당 좌표와 함께 움직이며 꼬리가 마커 가장자리에 닿는다. 화면 가운데 고정한 별도 floating card가 아니다.
- 브라우저 비교에서 설정 하단 14px 잘림을 발견해 간격을 줄였다. 지도 확대 때문에 마커/현재 위치가 잘리는 것도 원본의 상대 배치와 지도 비율에 맞췄다.

## 한계와 다음 단계

- 이 작업은 이미지 우선의 별도 프로토타입이다. 원본 폰 하드웨어 테두리/노치/OS 상태바는 웹 UI로 만들지 않았다. 지리 배경과 글꼴 렌더링은 실제 지도/브라우저에 따라 원본 래스터 이미지와 차이가 있다.
- 새 급경사 토글의 독립 경로 제약은 기존 엔진에 없으므로 선호 저장과 미연결 안내만 한다. 기존의 급경사 지표를 포함한 경로 비교는 유지한다. 기능 완성으로 쓰지 않는다.
- 새 지도 레이어 선택 기능, 원본 외의 횡단 시간 지도 화면 재디자인, 실시간 신호 안내를 추가하지 않았다. 지도 entry의 실제 모드는 기존 로컬 지도 화면으로 연결한다.
- 새 밝은 이미지 저장 양식은 구현했으나 실제 기기 다운로드 QA는 남아 있다. 배포 가능한 통합 앱으로 단정하지 않는다.
- 이 다섯 화면을 사용자에게 먼저 보여 준다. 승인 없이 운영 엔트리 교체·기본 브랜치 병합·운영 배포하지 않는다.

### 사용자 결정과 적용

- ‘조금 더 걸리더라도 편한 길’은 사용자 확정 방향이다. PM/UX가 제안한 별도 화면 없는 계획 미리보기는 구현 판단으로 채택했다. 길찾기 즉시 GPS를 기록하지 않고 기존 지도 화면 안의 ‘걷기 시작’에서 시작한다.
- BMAD PM/UX·설계/데이터·개발 역할이 검토했다. 역할별 근거는 TEAM_DIRECTION, DATA_INTEGRATION, NAVER_SETUP에 남긴다. 이후 통합은 Codex가 수행했다.
- 자동 학습 OFF의 속도 변경, 실제 출발 시각 초기화 누락, GPS 시작 위치 적용 누락, 지도 초기화/위치 마커 순서 문제를 새 표현 어댑터에서 고쳤다. 한국 신호 시각에는 kstSec()를 쓴다. 운영 알고리즘을 다시 쓰지 않았다.
- 첫 로고는 원래 SVG와 브랜드 폰트로 복원했다. 3.2초/건너뛰기. 원본 다섯 화면의 밝은 디자인과는 별개인 사용자 명시 예외다.
- 사용자에게 새 Maps 상품 등록·localhost/127.0.0.1/jjukgo 도메인 등록 위치를 안내했고, 실제 콘솔 수정 화면에서 이미 등록돼 있음을 확인했다. 등록/권한을 대신 변경하지 않았다. 받은 공개 Client ID는 로컬 .env.local에 두고 Git 제외했다. Client Secret은 받거나 사용하지 않았다.
- 실제 키로 네이버 지도·타일·경로·출처를 브라우저에서 확인했다. SDK 준비/부모 높이 0/리사이즈/최초 타일 로드/화면 전환 취소를 처리했다. 단순히 기존 지도 fallback만 되는 것을 연결 완료로 주장하지 않는다.
- 신호 모델은 개수용 xlist가 아닌 ID/방향이 있는 route.x를 사용한다. 기존 신뢰 기준을 통과한 예상 상태/잔여시간은 1초마다 갱신한다. 신호 버튼에 연결된 상세 창은 한 개이며, 기록 기간·신뢰 부족 이유를 보여 준다. 지도/마커 DOM 전체를 매초 갈아끼우지 않는다.
- 충분한 표본의 기록이 있으나 날짜 간 검증이 부족한 경우 ‘신호 기록 있음’과 ‘기록상 초록 구간(이력 추정)’을 보여 주되 현재 남은 시간이라고 쓰지 않는다. 저신뢰 현재 카운트다운과 ‘건널 수 있음’을 만들어 내지 않는다.

67e7788의 신호 manifest/시간대 조각만 작업 브랜치로 가져왔다: 10/14~10/30 17일, 패턴 후보 1734교차로. 기존 초기 작업 시점의 14일 자료로 고정하지 않는다. 단, 305초는 요청 간격이며 모든 교차로가 305초마다 성공 갱신됨을 뜻하지 않는다. 실시간 지도 설정은 꺼져 있고 검증된 실제 횡단 목록은 비어 있다.
