# 모바일 사용성 개선 + 실시간 보행 신호 지도 (2026-10-30)

## 사용자 요청(요약)
- 외부 점검(GPT가 공개 앱을 390×844로 써 본 결과) A~E를 재현하고, 지도·하단 패널 구조는 유지하며 고칠 것. 관찰과 제안을 구분.
- 실시간 보행 신호 지도: 새로고침 없이 실제 신호 상태로 아이콘이 바뀌게(카카오맵 지하철 실시간처럼). 시뮬레이션은 실제 기능이 아님. 검증된 일부 교차로부터. 횡단 시간 지도·예상 대기와 의미·색 분리. 키는 서버에서만.
- BMAD 관련 에이전트로 더블체크하고, 추가로 고칠 점을 적을 것. GPS 설정 단계가 많음(네이버·카카오처럼 쉽게). 데이터가 더 들어오면 계속 갱신.

## 결정·결과
- BMAD UX 디자이너(Sally)·아키텍트(Winston) 에이전트로 재현·검토. 결과는 `docs/reviews/2026-10-30-mobile-ux.md`, `docs/REALTIME_SIGNALS.md`에 반영.
- 모바일: 재현된 A~E와 에이전트 추가 항목을 고침(전후 화면 `reports/ux/2026-10-30/`).
