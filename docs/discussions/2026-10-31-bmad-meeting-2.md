## 2. 요약 화면(오늘의 걸음) 새 구성
- 첫 줄: "서울숲까지 걸었어요" 또는 "경로 중 1.2km를 걸었어요"
- 걸은 시간(GPS 실측). 끝까지 걸었으면 "출발 전 예상 35분"을 같이
- 걸은 거리, 멈춘 시간(GPS 기록에서 움직이지 않은 시간)
- **이 길의 신호(출발 전 예상)**: "신호 대기 약 32초 · 신호 2곳". 두 길 모두 대기를 계산할 수 있고 10초 넘게 적을 때만 "빠른 길보다 신호 대기가 약 N초 적은 길이었어요"
- 작은 지도(출발·도착 이름표는 지도 표시와 겹쳐 뺌)
- 뺀 것:
  - 계단·오르는 높이·급경사 4칸(신호와 무관하고 '미확인'이 많음)
  - 엄지 문장
  - "기록 없음" 칸
- 화면이 길면 스크롤되고, 아래 버튼은 고정

## 3. 미룬 것
- 검색 결과에 주소·거리 표시, 오타 제안
- 끌어서 높이를 바꾸는 3단 시트
- 확인 창(confirm)을 앱 안 시트로 바꾸기
- 길을 벗어나면 자동으로 다시 찾기(지금은 버튼)
- 화면이 꺼져도 위치 받기(웹의 한계)
- 실기기에서 도착 판정 확인(PM 시뮬레이션은 도착이 안 됐고 QA 시뮬레이션은 됐음, 점 간격 차이로 추정)

## 4. 사용자 추가 요청: "카카오나 네이버 맵의 장점은 따와"
가져온 것(일반적으로 알려진 지도 앱 기능 기준):
- **출발 시각 바꾸기**(지금 / 5·10·15분 뒤): 바꾸면 신호 대기를 다시 계산한다.
  - 성수역→서울숲, 화 14:10 기준: 지금 약 32초, 5분 뒤 약 29초, 10분 뒤 약 2분 58초.
  - 지도 앱의 출발 시각 설정에 쭉고의 신호 예측을 붙인 기능이다.
- **경로 공유**: 공유 창이 있으면 공유하고, 없으면 링크를 복사한다.
- **안내 중 화면 꺼짐 방지**(Wake Lock): 화면이 꺼지면 웹에서 위치가 멈추는 문제를 줄인다. 지원하지 않는 브라우저는 그냥 넘어간다.
- **음성 자동 안내**: 위 카드 안내가 바뀔 때 읽는다. 숫자만 바뀐 같은 안내는 다시 읽지 않는다.
- **검색 결과에 거리·분류**: 기준점은 내 위치, 없으면 반대쪽 장소. 예: 서울숲 1.6km · 명소.
- 앞서 넣은 것: 위 출발·도착 막대, 경로 카드, 다른 후보 길 회색 표시, 내 위치 따라가기, 지도 버튼 정리.

**남은 것(코덱스 제안):**
- 홈을 지도 우선 화면으로 + 집·회사 즐겨찾기
- 끌어서 높이를 바꾸는 시트, 경로 상세 목록
- 앱 안 확인 시트, 검색 주소·오타 제안
- 근거와 순서는 [CODEX_NEXT](../CODEX_NEXT.md)에 있다.

**확인:**
- 출발 시각 칩, 공유 링크, 검색 거리를 직접 확인했다.
- 혜화역→낙산공원을 초당 약 1.5m로 끝까지 걸어 도착과 요약("낙산공원까지 걸었어요 · 10분 · 800m · 출발 전 예상 15분")을 확인했다.
- 페이지 오류 0건.
- 화면 꺼짐 방지와 음성은 실기기에서만 확인할 수 있다.
