## 프로토타입이 안 열리는 문제

- 사용자: ‘왜 프로토타입 안열림?’
- 확인: GitHub에는 `seoul/` 실행 데이터가 빠져 있어 지도 초기 로딩이 실패했다. HTML만으로 실행되지 않았다.
- 사용자 제공 원본: https://claude.ai/artifact/PdN4J4FMDoX31ErpxzqCPE#home
- 원본 아티팩트에서 지도 데이터 개별 파일을 복원했다. 로컬 서버를 실행하고 지도와 실제 경로 결과를 확인했다.
- 사용자: ZIP은 용량을 잡아먹어 싫으니 GitHub에 올려 달라고 요청.
- 처리: ZIP을 저장소에 추가하지 않고 지도 데이터 375개를 포함해 GitHub 작업 브랜치에 push. 모든 경로 데이터는 체크아웃만으로 확보 가능하다. 개별 파일 역시 로컬 공간은 사용한다.

## 서비스 기획 스킬·플러그인 탐색

- 사용자: 서비스 기획자처럼 생각하는 스킬/플러그인을 찾아 있으면 설치하고 쭉고에서 무엇을 더 고쳐야 하는지 검토해 달라고 요청.
- Product Design을 발견하고 설치 경로를 제시. 이후 연결과 스킬 사용 가능 상태가 확인됐다.
- `haniabdemai/product-management-skills`를 찾아 원본 내용을 확인하고 설치를 시도했으나, 자동 승인 검토가 사용량 제한으로 완료되지 않아 설치 명령이 실행되지 않았다. 보안 위험 판정은 아니었다.
- 사용자가 개발자·디자이너·기획자 등 다수 에이전트가 한 팀으로 협업하는 플러그인도 찾아 달라고 요청.
- 조사 후보:
  - [BMAD](https://github.com/bmad-code-org/BMAD-METHOD): PM·UX·개발·설계·분석 역할, 기획부터 구현까지의 워크플로.
  - [Agency Agents](https://github.com/msitarzewski/agency-agents): 직군별 전문 역할 정의와 Codex 변환 지원.
  - [Oh My Codex](https://github.com/Yeachan-Heo/oh-my-codex/): 에이전트 실행 조율. Windows 팀 실행에는 환경 구성을 확인해야 함.
  - Superpowers: 계획·테스트·디버깅·협업 절차. 플러그인 검색에서 설치 가능 항목 확인.
- 판단: 현재 쭉고에는 무엇을 만들지와 검증 범위를 논의하는 BMAD 방식이 적합하다고 추천. 이것은 에이전트 판단이며 제품 방향의 사용자 확정은 아니다.
