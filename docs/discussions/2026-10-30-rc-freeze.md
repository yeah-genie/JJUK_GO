# RC freeze 결정 (2026-10-30)

## 사용자 결정
- 이제는 "더 만들기"가 아니라 **"검증하고 얼리기"** 단계.
- 이번에 가장 큰 개선으로 본 것: 검색 맥락 표시, 거리 기준 명시, 탭 바꿔도 상세 유지, 조건 조정 인라인, GPS 허용 시 내 위치 자동 출발지, 횡단 수치 기준 통일.
- **실시간 신호 지도는 당분간 손대지 않는다.** 구조만 두고 production OFF 유지. `404 = 사용승인 없음`은 추정이므로 T Data에서 실제 신청 상태를 확인한 뒤 판단.
- **수정 기준(freeze 규칙): 아래 셋 중 하나일 때만 고친다.**
  1. 사용을 막는가?
  2. 잘못 이해하게 만드는가?
  3. 신뢰를 깨는가?
  그 밖의 UX 개선 제안(에이전트가 찾은 것 포함)은 받아들이지 않고 'freeze 뒤 후보'로만 적는다.
