# 장기 방향: "언제 나가야 안 늦지?" (2026-10-28 메모)

> **상태 정정(2026-10-28):** 이 문서는 장기 아이디어다. 현재 합의한 방향은 [비슷하게 걸리면 덜 힘든 Walking 경로](../PRODUCT_DIRECTION.md)이며 신호+경사+계단을 먼저 고려한다. 지하철·버스는 Walking 검증 이후에 검토한다. 이 문서를 현재 MVP나 타깃 확정으로 읽지 않는다.

> 당장 구현하지 않는다. 지금의 "신호 적은 도보 길찾기"가 검증되거나 막히면 여기로 다시 설계한다.

## 1차 페르소나
**정해진 시간까지 도착해야 하고, 버스·지하철 환승을 매일 하는 수도권 통근자.**

- 예: 지수(27) · 09:00 출근 · 집 → 버스 → 지하철 → 회사
- 지도엔 43분, 실제로는 39–55분으로 흔들림. 버스·환승 하나 놓치면 +5–10분
- 매일 8:05에 나갈지 8:10에 나가도 될지 애매함
- 길은 너무 잘 안다. 궁금한 건 하나: **"오늘 몇 시에 나가야 안 늦지?"**
- 더 좁히면: "환승 한 번 때문에 5–10분이 흔들리는 사람"

## 질문이 다르다
- 네이버/카카오: "어떻게 갈까?"
- 쭉고: **"언제 나가야 할까?"** → 매일 같은 길이라도 매일 열 이유가 생김

## 첫 화면
처음 한 번만 등록: 🏠 집 · 🏢 회사 · ⏰ 09:00까지 도착

아침에 열면:
```
오늘은 08:07까지 출발하세요
예상 도착 08:48 ~ 08:56
🟢 제시간 도착 가능성이 높은 편
평소보다  🚦 신호 +1분  🚌 버스 정상  🚇 지하철 정상
08:12 이후 출발하면 여유가 급격히 줄어요.
```

## 기능 4개
1. **출발 마지노선** (킬러 기능): 08:07 🟢 안정적 / 08:12 🟡 빠듯 / 08:17 🔴 지각 위험 증가
2. **다음 거 타도 돼?**: "방금 열차 놓침 · 다음 열차 +4분 · 그래도 08:57 도착 예상 · 🟢 뛰지 않아도 돼요"
   → 불확실성을 줄여 무리하게 뛰는 행동을 줄인다(사회적 가치)
3. **빠른 길 vs 안전한 길**: A 41분(환승 2분, 놓치면 +9분) vs B 45분(환승 여유 7분, 변동 적음) → "오늘은 B 추천"
4. **오늘 평소랑 달라?**: 평소면 한 줄("평소대로 08:05 출발"), 문제 있는 날만 경고("2호선 지연, 8분 일찍")

## 2차 페르소나 (1차 검증 뒤)
- 절대 늦으면 안 되는 이동: 병원·기차·면접 ("KTX 15:10인데 몇 시까지 나가야 안전하지?")
- 정해진 시간에 데려다줘야 하는 보호자 ("8:50 등원")
- 이동 속도가 평균과 다른 사용자(환승 4분이 실제론 6–7분) → 접근성·고령자로 확장

## MVP 범위
집→회사 즐겨찾기 1개 + 도착 목표 시각 + 오늘 출발 마지노선. 거대한 멀티모달 길찾기 앱일 필요 없음.

## 데이터 근거 (확인 필요)
- 서울시 교통카드 O/D 데이터로 출근 시간대 버스·지하철 혼합 이용, 환승 횟수·지역 분석
- 서울시 환승경로 API
- 지금 모으는 C-ITS 신호 패턴 → 도보 구간 마지노선 보정에 재사용 가능
