## 확인이 필요한 것
- HUG 명단 API가 이름·ID 검색을 지원하는지, 개인정보를 어떻게 다뤄야 하는지.
- 공항 혼잡도 API의 호출 간격 제한(서울 신호 API처럼 걸릴 수 있음).
- 전국 통합 신호등 API가 한 번에 여러 교차로를 주는지, 호출 간격 제한이 있는지, 서울 교차로가 포함되는지.
