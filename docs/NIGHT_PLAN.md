# 밤샘 작업 계획 (2026-10-27 밤 → 10-28 아침)

요청: "다른 지역도 업데이트 해. 지도가 잘 안보여. 서비스 기획자라고 생각하고 검증하면서 해."

## 목표 (아침에 확인할 결과)
1. **서울 전체가 진짜 지도로 보인다.** 어디로 끌어도 도로·건물·공원·강·지명·역 이름이 나온다.
2. **서울 어디든 길찾기가 된다.** 장소를 검색하거나 지도를 눌러 출발·도착을 정하면 최단 길과 쭉고 길이 나온다.
3. **결과 화면에서 지도가 잘 보인다.** 아래 시트를 끌어 올리고 내릴 수 있고(네이버 지도처럼 3단), 처음엔 지도가 화면 절반 이상을 차지한다.
4. **숫자는 정직하다.** 신호 패턴을 모은 곳(테헤란로 7개 교차로)만 기다림을 보여주고, 나머지는 "신호 N곳 · 패턴 없음"으로 센다. 예시 값은 계속 "예시"라고 표시한다.
5. 웹앱(같은 링크)에 올리고, 리포에 커밋·푸시하고, 검증 결과를 이 문서 아래에 적는다.

## 구현할 것
| 영역 | 내용 |
|---|---|
| 지도 데이터 | BBBike 서울 추출본(OSM, ODbL)의 벡터 타일을 묶음 파일로 나눠 웹앱 옆에 올린다. 필요한 칸만 받아 그린다. 한글 글자는 기기 글꼴로 그린다 |
| 지도 스타일 | 네이버 지도 느낌: 밝은 바탕, 흰 도로+회색 테두리, 초록 공원, 파란 물, 역은 초록 원 + 이름, 큰길 이름 표시. 확대 14 이상에서 건물, 16 이상에서 신호 교차로 표시 |
| 길찾기 | 서울 보행 그래프(28만 노드)를 2.2km 칸으로 나눠 필요한 칸만 받는다. 최단 = 거리, 쭉고 = 걷는 시간 + 신호 비용(패턴 있으면 도착 시각 기준 예상 대기, 없으면 평균 45초). 지하도·육교는 신호를 지나지 않는 것으로 계산 |
| 검색 | 역·동네·대학·병원·명소·카페 등 1.7만 곳. 검색 화면(최근 검색 포함). 지도를 눌러 "여기서 출발/여기까지" |
| 결과 화면 | 끌 수 있는 시트(접힘·중간·펼침), 경로 카드 압축, 패턴 없는 구간 안내를 결과 화면 안에 합침 |
| 나머지 화면 | 걷는 중·도착 카드·횡단보도 목록·신호 상세·출발 시각 추천을 어떤 경로에서도 동작하게 일반화 |
| 범위 밖 | 4km 넘게 떨어진 곳은 "걷기엔 멀어요"로 안내 |

## 검증 기준 (기획자 체크리스트)
- [ ] 폰(390×844)·작은 폰(360×640)·앱 옆 패널(470×850) 세 크기에서 결과 화면 지도 영역이 화면 높이의 45% 이상
- [ ] 버튼·시트·배지가 서로 겹치지 않음
- [ ] 강남역, 시청역, 홍대입구역, 잠실역, 여의도, 성수동 카페 검색 → 결과 나옴, 경로 길이/직선거리 비율 1.0–1.8
- [ ] 역삼역→선릉역은 패턴 기반 기다림 표시, 다른 지역은 "패턴 없음" 표시
- [ ] 지도 끌기·확대·내 위치·북쪽 보기 동작, 콘솔 오류 0
- [ ] 첫 화면 데이터 내려받기 3MB 이하, 길찾기 계산 1초 이하
- [ ] 기존 테스트 통과

## 하지 않는 것
- 실제 GPS 위치(웹앱 권한 문제로 "내 위치"는 역삼역 예시로 둠)
- 네이버 지도 SDK(키·도메인 필요)
- 버스·지하철 연계
