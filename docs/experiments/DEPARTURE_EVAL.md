# 출발 시각을 고르면 얼마나 덜 멈추나 (광화문 3곳 실측, 2026-10-28)

`scripts/eval_departure.js` · 패턴 `gwanghwamun_plans.json`

## 방법
- 실측 패턴이 있는 교차로 3곳: 정동(1537)·구세군회관앞(2691)·서울역사박물관(1619). 모두 주기 140.0초로 일정(관측 37–156분).
- 이 3곳 중 **2곳 이상을 지나는** 길 82·86쌍(광화문 반경 1.6km 안 장소끼리, 직선 0.5–2.0km)을 뽑아, 출발 시각을 5초씩(0–175초) 바꿔 가며 멈춤을 셈. 길은 출발 시각마다 '최단 시간'으로 다시 찾음.
- v1/v2: 방향 대응(어느 방향 신호가 어느 횡단보도인지) 가정을 두 가지로 바꿔 본 것. 대응이 가정이라 결과가 크게 달라지지 않는지 보려는 용도.

## 결과
| | v1 | v2 |
|---|---|---|
| 지금 출발하면 평균 | 멈춤 1.34번, 기다림 76초 | 멈춤 0.90번, 기다림 29초 |
| 60초 안에 출발 시각을 고르면 | 멈춤 0.55번 덜, 44%의 길에서 줄어듦 | 0.72번 덜, 55% |
| 120초 안에 고르면 | 0.72번 덜, 60% | 0.85번 덜, 67% |
| **도착이 늦어지지 않는데(+10초 이내) 60초 안에 출발해서 덜 멈추는 길** | **41%** (평균 1.21번 덜) | **43%** (평균 1.32번 덜) |

예: 푸르파파 → 사직동(1.7km): 지금 출발하면 2번 멈추고 67초 기다리지만, **10초 뒤에 출발하면 0번 멈추고 0초**, 도착은 오히려 70초 빠름.

## 해석
- 길을 바꾸는 효과(서울 전체 10–20%, 신호 1–2곳 덜)보다 **출발 시각을 몇 십 초 조절하는 효과가 훨씬 크다**. 신호 패턴을 알아야 가능하고, 지도 앱엔 없는 기능이다.
- 이유: 연동된 연속 신호는 한 번 초록에 걸치면 이어서 초록을 받고, 어긋나면 연달아 걸린다. 출발 시각이 그 위상을 결정한다.

## 한계 (중요)
- 교차로 3곳, 같은 동네. 선택 편향: 모은 신호를 2곳 이상 지나는 길만 골랐다.
- **방향 대응은 가정**이다(v1/v2로 흔들어 봤지만 현장 확인 안 함).
- 패턴은 새벽 데이터. 출퇴근 시간에 신호 계획이 달라지면 결과가 달라진다.
- 보행자가 신호에 맞춰 걷는 속도를 1.2m/s로 일정하다고 가정한다.
- 이 결과는 "패턴을 알면 이 정도까지 가능하다"이지, 실제 사용자가 겪을 효과의 증명이 아니다. 현장에서 한 번 검증하면 좋다.
