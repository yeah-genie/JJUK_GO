# 신호 주기 찾기와 대기시간 예측

코드: `src/jjukgo/signal/cycle.py`, 실행: `scripts/analyze_cycles.py`, 그림: `scripts/plot_folded.py`

## 방법
고정 주기 신호는 시각 t의 상태가 `(t − 기준시각) mod 주기`에만 달려 있다. 1초 단위 관측(초록=1, 빨강=0)을 후보 주기마다 접어 같은 위상끼리 모으고, 초록·빨강이 가장 덜 섞이는(불순도가 가장 낮은) 주기를 고른다.
- 2배, 3배 주기도 똑같이 깨끗하게 접히므로 거의 같은 점수면 가장 짧은 주기를 고른다.
- 1초 표본으로는 주기가 0.1초쯤 달라도 똑같이 깨끗하므로, 그 범위의 가운데 값을 고른다(외삽 오차 최소).
- 위상은 관측 시작 시각 기준으로 잰다. 1970년 기준으로 재면 주기의 미세한 차이가 수백만 바퀴 누적돼 위상이 완전히 틀어진다(실제로 겪은 버그).
- 검증: 앞 60%로 주기를 찾고 뒤 40%의 시각마다 "도착하면 몇 초 기다리나"를 예측해 실제 기록과 비교한다.
