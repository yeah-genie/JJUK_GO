# 쭉고 vs 최단: 서울 300쌍 비교 (2026-10-28)

> **정정(같은 날 오후):** 아래 '1차' 결과의 최단은 거리만 따진 길이라 비교가 불공평했다. 신호 기다림까지 따진 '최단 시간'을 기준으로 다시 쟀고, 그 결과가 맨 위 '2차'다. 1차 숫자(51.8%·62.7%)는 부풀려진 값이므로 인용하지 말 것.

`scripts/eval_routes.js` · 결과 원본 `route_eval_300.json`

## 2차 (기준 변경): 최단 = 걷는 시간 + 신호 기다림이 가장 작은 길
- 최단 시간: 패턴 아는 신호는 도착 시각의 예상 대기, 모르는 신호는 평균 대기 45초를 시간에 더해 가장 빨리 도착하는 길.
- 쭉고: 거기에 멈춤 1번당 15초를 더해 덜 멈추는 길을 찾되, **멈춤·기다림·신호 수 중 어느 것도 늘지 않고, 도착이 30초보다 늦지 않을 때만** 보여줌. 아니면 최단 시간 길이 곧 쭉고 길.
- 같은 300쌍(276쌍 성공), 출발 08:40.

| | A. 지금(타이밍 모름) | B. 가정 실험(타이밍 안다고 가정) |
|---|---|---|
| 쭉고가 최단 시간과 다른 길 | **55/276 (19.9%)** | **24/276 (8.7%)** |
| 평균 신호 수 | 2.67 → 2.41곳 | 2.67 → 2.62곳 |
| 다를 때 | 신호 1.3곳 덜 | 멈춤 1.0번 덜, 기다림 69초 덜, 더 걷는 거리 중앙값 62m |
| 전체 평균 멈춤·기다림 | – | 멈춤 1.51 → 1.42번, 기다림 81 → 75초 |
| 쭉고가 더 나쁜 경우(멈춤·신호 늘거나 기다림 5초+ 늘거나 30초+ 늦음) | 0 | 0 |
| 도착이 5초 넘게 늦은 경우 | 11 | 7 (모두 30초 이내) |

해석:
- 공정한 기준에선 쭉고의 이득이 **훨씬 작다**. 기다림을 알고 시간으로 계산하면 최단 시간 길이 이미 신호를 많이 피한다.
- 쭉고만의 몫은 "도착은 거의 같은데 덜 멈추는 길"(1–2곳 덜)이고, 그런 쌍이 10–20%다.
- B는 가짜 패턴을 쓴 가정이다. 실제 패턴이 들어오면 다시 잰다.

## 1차 (거리만 따진 최단, 참고용)

### 방법
- 서울 검색 목록(역·동네·명소 등, 카페·건물 제외)에서 직선거리 0.5–2.5km인 출발·도착 쌍 300개를 고정 난수로 뽑음. 276쌍 길찾기 성공(24쌍은 보행망이 이어지지 않음).
- 보행망: OSM 서울 + 큰길 보도·횡단보도 생성(`scripts/sidewalks.py`). 신호는 **건너는 횡단보도**에서만 셈.
- 최단 = 거리 최소. 쭉고 = 걷는 시간 + 신호 비용(패턴 없는 신호 45초, 있는 신호는 도착 시각의 예상 대기 + 멈춤 15초).
  쭉고가 보이는 숫자(멈춤·기다림·신호 수)로 나아진 게 없으면 최단을 그대로 씀.
- 출발 08:40, 걷는 속도 1.2m/s.

## B. 가정 실험: C-ITS 신호 약 2,700곳의 타이밍을 안다면
실제 패턴이 아니라 **가짜 패턴**(주기 150초, 초록 25–35초, 시작 시각은 교차로 ID로 만든 의사난수)으로 계산. "타이밍을 알면 얼마나 달라질 수 있나"를 보는 값이지 실제 효과가 아님.

| | 값 |
|---|---|
| 쭉고가 최단과 다른 길 | **173/276 (62.7%)** |
| 전체 평균 멈춤 | 최단 2.17번 → 쭉고 1.35번 |
| 전체 평균 기다림 | 최단 135초 → 쭉고 74초 |
| 다를 때 | 멈춤 1.3번 덜, 기다림 98초 덜, 도착 평균 36초 빠름(중앙값 10초), 더 걷는 거리 중앙값 45m |
| 다를 때 도착이 늦어진 경우 | 50쌍 (멈춤을 줄이려고 멈춤 1번에 15초 비용을 둬서, 덜 멈추지만 조금 늦게 도착하는 길을 고름) |

## 해석
- 횡단보도 기준으로 세자 **신호 개수만으로도 절반 넘게 다른 길**이 나온다(예전 노드 기준에선 대부분 같았음). 앞서 본 예시 7개는 역→명소처럼 큰길을 따라가는 길이라 차이가 작았다.
- 타이밍을 알면 멈춤·기다림이 크게 준다(가정 실험). 실제 효과는 테헤란로 실측 패턴으로 다시 재야 한다.
- 먼 길(10km 이상)은 한강·중랑천 산책로처럼 신호가 거의 없는 길을 골라 신호를 25–37곳 덜 지난다(7–10분 더 걸음).

## 한계
- 큰길 보도는 차로 수로 폭을 추정해 그린 근사치. 횡단보도 표시가 빠진 곳은 실제로 건널 수 있어도 못 건너는 것으로 계산될 수 있음.
- 골목 교차로 신호는 여전히 "지나가면 셈"(건너는지 구분 못 함).
- 신호 위치는 C-ITS 교차로 + OSM 신호 표시. 둘 다 없는 신호는 모름.
