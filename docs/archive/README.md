# 보관 문서 (현재 기준 아님)

2026-10-29 정리에서 **더 이상 현재 제품 방향·화면·계획의 기준이 아닌 문서**를 지우지 않고 이곳으로 옮겼다. 당시의 판단과 근거를 보존하기 위한 기록이며, 현재 동작이나 요구사항의 근거로 쓰지 않는다. 현재 기준은 [`../PRODUCT_DEFINITION.md`](../PRODUCT_DEFINITION.md), [`../MVP_PLAN.md`](../MVP_PLAN.md), [`../PRODUCT_SPEC.md`](../PRODUCT_SPEC.md), [`../DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md), [`../HANDOFF.md`](../HANDOFF.md)이다.

| 문서 | 왜 보관으로 옮겼나 |
|---|---|
| `PROPOSAL.md` | 최초 기획서. 신호 대기 최소화 중심이며 이후 방향(횡단 여유·서두르지 않는 길)과 다르다 |
| `PRODUCT_DIRECTION.md` | "비슷하게 걸리면, 덜 힘든 길" 방향 기록. 이후 정의로 대체됐다(참고 논문 목록과 단계별 제안은 이곳에 남아 있다) |

| `PRODUCT_REVIEW.md` | 이전 화면(출발 카드 중심) 감사. 현재 화면과 다르다 |
| `FIRST_DEMO_PLAN.md`, `WALKING_DEMO.md` | Walking 1차 데모 계획·구현 기록. 현재 UI와 다르다(스크린샷은 정리에서 삭제) |
| `BMAD_TEAM.md` | BMAD 설치 전의 팀 운영 메모. 이제 BMAD 6.12.4가 설치돼 있다(`_bmad/`, `.claude/skills/`) |
