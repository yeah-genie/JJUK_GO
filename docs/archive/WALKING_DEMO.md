# 기존 쭉고 프로토타입의 Walking 확장

2026-10-28. 작업 브랜치 `codex/refine-time-results`.

사용자 요청대로 기존 Claude 프로토타입에서 복원한 HTML/JavaScript를 직접 수정했다. 노랑·아스팔트 배색, 지도, 끌어서 펼치는 하단 시트, 경로 카드와 글꼴을 유지한다. Claude 원본 공유 아티팩트를 원격 수정한 것은 아니다.

## 연결한 기능

- 홈의 **내 위치로 출발**에서 사용자 허용 후 현재 위치를 출발지로 사용한다. 지도 위치 버튼은 현재 위치로 화면을 이동한다.
- 결과에서 **+1/+2/+3분** 추가시간을 고른다. 빠른 길과 신호·검출 계단·지형 상승량을 고려한 후보를 비교한다. 차이가 없으면 더 나은 후보를 찾지 못했다고 표시한다.
- **걷기 시작**은 실제 위치 갱신을 연결한다. 경로에 투영한 진행 거리, 남은 거리와 걷기만의 남은 시간을 표시한다. 신호 때문에 실제 멈춘 횟수나 실시간 초록불은 추측하지 않는다.
- **움직임 시연**은 이전 애니메이션을 별도 버튼으로 제공한다. 실제 위치·이동 기록이 아님을 표시한다.
- 권한 거절, 시간 초과, 서울 지도 범위 밖, 오차100m 초과, 30초 이상 오래된 위치, 경로 이탈, 갑작스러운 위치 점프를 처리한다. 화면 전환·숨김·종료 시 위치 구독을 해제하고 다시 연결 버튼을 제공한다.
- GPS 좌표는 메모리에서만 사용하며 최근 검색이나 앱 서버에 기본 저장하지 않는다. 지도·검색·지형 파일은 미리 포함된 정적 데이터다.

## 실제 데이터와 수치의 범위

계단은 기존 OSM 그래프의 `cls=3`을 연속 구간으로 묶고 길이를 합산한다. **0구간은 ‘검출된 계단0’이며 실제 계단 없음의 보장이 아니다.** 기존 그래프에서 입체보행 `cls=4`가 우선 분류된 계단은 놓칠 수 있어 입체구간 미확인을 표시한다. 서울시 OA-21207 공간파일은 아직 통합하지 않았다.

지형은 [Mapzen Terrain Tiles on AWS](https://registry.opendata.aws/terrain-tiles/)의 공개 Terrarium 타일33장을 받아 약120m 간격으로 축소한 `seoul/terrain.json`(703,645바이트)을 사용한다. [공식 RGB 변환식](https://github.com/tilezen/joerd/blob/master/docs/formats.md)에 따라 높이를 복원하고, 노드에서 보간해 진행 방향의 양의 고도차를 합산한다. 다리·지하도는 지표면 고도로 대신 계산하지 않는다. 약120m는 이 파생망의 간격이며 원자료 정확도나 길의 실제 높이 정확도가 아니다. 작은 골목의 급경사·계단 높이·실제 피로를 검증한 자료가 아니다. 국토지리정보원 DEM을 확보한 것으로 기록하지 않는다.

경로 후보는 시간 중심/신호·계단·상승량 고려/더 강한 회피의 세 가중치 탐색이다. 선택 비용의 계수는 초기 구현 가정으로 검증된 피로 점수가 아니다. 시간예산 검사는 알려진 신호 대기+모르는 신호당45초 가정을 포함한다. **화면의 시간과 도착 시각에는 미확인 신호 대기가 빠져 있으며**, 그 범위를 카드 각주에 표시한다. 모든 시간제약 최적 경로나 무장애 경로를 보장하지 않는다.

신호는 기존 `2026-10-28 08:40` 기준 패턴 시연이다. 실제 위치 연결과 실시간 신호 제공은 별개다. 걷는 화면은 다음 횡단보도까지 거리만 안내하고 실제 신호 확인을 요청한다. 요약 카드도 실제 걸은 기록이 아닌 경로 시연 예측으로 표시한다.

- `node scripts/check_walk_browser.cjs`: 실제 서울 그래프·지형 파일을 로드하고 가상 GPS로 진행·이탈·권한 거절·추적 해제·좌표 비저장·반응형 화면 검사. 재현에 로컬8766 서버와 Playwright 필요.

## 실행·배포

소스는 `prototype/src/template.html`과 `prototype/src/app.js`. `python scripts/build_prototype.py`로 배포용 `prototype/index.html`을 생성한다. `python -m http.server 8766 --bind 127.0.0.1 --directory docs/prototype` 실행 후 `http://127.0.0.1:8766/#home`에서 확인한다.

Vercel용 `vercel.json`은 기존 정적 폴더를 그대로 배포하도록 지정한다. HTTPS와 `Permissions-Policy: geolocation=(self)`를 사용한다. 위치를 앱 시작 때 자동 요청하지 않는다. 모바일 공유에는 배포된 HTTPS 직접 링크가 필요하고, PC의 localhost는 휴대전화 공유 링크가 아니다.

## 배포 결과

Vercel 팀 승인 반영 후 `jjukgo` 프로젝트 생성과 배포가 완료됐다. 대표 주소: **https://jjukgo.vercel.app/#home**. 첫 배포 `dpl_3XDNBdT24WddWg3dZXDacedWp74P`, 코드 `3a7eeb2`, 상태 READY 확인. 다른 기존 프로젝트는 수정하지 않았다.

로그인/쿠키 없는 HTTP 요청으로 `/`, `/seoul/graph/index.json`, `/seoul/terrain.json`, `/seoul/tiles/index.json` 모두200과 실제 앱/JSON 본문, `Permissions-Policy: geolocation=(self)`를 확인했다. 브라우저에서도 HTTPS 홈을 열었다.

처음 API 응답에 SSO 보호 설정이 보여 전체 보호 해제를 요청했으나 자동 승인 검토가 명시적 공개 승인 부족을 이유로 거절했다. **그 변경은 적용되지 않았다.** 이후 확인한 대표 도메인은 기본 설정만으로 공개 접근이 가능했다. 사용자도 '링크로 누구나 사용하도록 공개'를 명시적으로 선택했다. 이미 공개인 대표 주소를 위해 추가 보호 설정을 바꾸지 않았다. 별도 미리보기/커밋 주소의 접근 정책까지 같다고 가정하지 않는다.

걷기 화면에서는 과거 패턴의 신호색/대기초 마커를 숨기고 횡단보도 위치만 표시한다. 위치 버튼을 눌러도 진행 중 위치 구독이 끊기지 않는 회귀 검사 추가. 화면 기록은 지도 로드 후 다시 저장했다.
