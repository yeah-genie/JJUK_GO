# 서울 프로토타입 데이터

2026-10-28 사용자 소유 쭉고 아티팩트에서 복원한 375개 실행 파일입니다. ZIP이 아닌 개별 파일로 보관합니다.

- `tiles/`: 지도 벡터 타일 묶음과 인덱스
- `graph/`: 보행 그래프 조각과 인덱스

- `search.json`: 장소 검색 목록
